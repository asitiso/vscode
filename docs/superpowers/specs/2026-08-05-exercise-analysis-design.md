# 운동 상세 분석 설계

## 목표

운동 리포트에서 특정 운동을 선택하면 해당 운동의 누적 성과, 최고 기록, 최근 변화, 전체 과거 기록을 한 화면에서 확인할 수 있도록 한다.

## 범위

이번 버전은 핵심 분석형으로 구현한다.

포함:
- 운동별 최고 기록 최대 3개
- 누적 운동일, 기록 횟수, 총 세트, 총 반복, 총 운동 시간
- 최근 4회 미니 선 그래프
- 최근 4회 기록 요약 카드
- 전체 기록 보기
- 전체 기록 최신순 목록과 20개 단위 더 보기
- 기록 선택 시 기존 날짜 상세 바텀시트 재사용

제외:
- 총볼륨 및 평균 중량
- 장기 추세 그래프
- 검색, 필터, 정렬 변경
- 운동별 목표 설정
- 별도 분석 데이터 저장

## 화면 흐름

운동 상세 분석은 운동 리포트 위에 열리는 별도 화면으로 구성한다. 뒤로가기를 누르면 기존 주간·월간 선택과 보고 있던 기간을 유지한다.

진입 위치:
- 주간·월간 리포트의 인기 운동
- 주간 날짜별 운동 목록
- 월간 날짜 상세 바텀시트의 운동명
- 전체 기록 목록에서 날짜 상세 바텀시트로 재진입

## 상세 화면 구성

1. 운동명과 최근 운동일
2. 최고 기록 카드 최대 3개
   - 최고 중량
   - 최장 시간
   - 최다 반복
3. 누적 통계
   - 운동일
   - 기록 횟수
   - 총 세트
   - 총 반복
   - 총 운동 시간
4. 최근 4회 미니 선 그래프
5. 최근 4회 기록 요약 카드
6. `전체 기록 보기` 버튼
7. 전체 기록 최신순 목록

## 집계 구조

분석 데이터는 별도로 저장하지 않고 기존 `workoutLogs`에서 매번 계산한다.

핵심 인터페이스:

```ts
buildExerciseAnalysis(workoutLogs, exerciseId)
buildExerciseHistory(workoutLogs, exerciseId)
buildExerciseTrend(records)
```

## 수행 기록 단위

같은 날짜에 같은 운동이 여러 로그에 들어 있어도 각 로그를 한 번의 수행 기록으로 유지한다.

- 운동일: 날짜 중복 제거
- 기록 횟수: 로그별 운동 등장 횟수
- 총 세트: 모든 기록의 세트 합계
- 총 반복: `reps * Math.max(1, sets ?? 1)` 합계
- 총 운동 시간: 모든 기록의 시간 합계
- 최고 중량: 개별 수행 기록 중 가장 높은 중량
- 최장 시간: 개별 수행 기록 중 가장 긴 시간
- 최다 반복: 개별 수행 기록 중 총 반복이 가장 높은 값

## 최근 4회 기준

기록은 날짜와 생성 시각을 기준으로 최신순 정렬한다. 최신 4개 수행 기록을 최근 기록과 그래프에 사용한다.

대표 그래프 지표 우선순위:

1. 중량 기록이 하나라도 있으면 최고 중량
2. 중량 기록이 없고 시간 기록이 있으면 운동 시간
3. 그 외에는 총 반복

최근 4개 중 대표 수치가 없는 기록은 그래프에서 `0`으로 표시한다. 기록 카드에는 실제 저장된 값만 표시한다.

## 운동명과 카테고리

운동명은 다음 우선순위로 결정한다.

```ts
entry.exerciseName
EXERCISES_BY_ID[exerciseId]?.name
'삭제된 운동'
```

사용자 직접 등록 운동이 삭제되어도 과거 기록 이름을 유지한다. 카테고리는 기본 운동 정의를 우선 사용하고, 찾을 수 없는 사용자 운동은 `기타`로 처리한다.

## 최고 기록 카드

운동에 맞는 값이 있는 카드만 최대 3개 표시한다.

- 최고 중량
- 최장 시간
- 최다 반복

해당 값이 하나도 없더라도 누적 통계와 기록 목록은 표시한다.

## 전체 기록 보기

- 최신순 세로 목록
- 같은 날짜의 기록도 각 수행 기록별 별도 카드
- 카드 표시 항목: 날짜, 중량, 시간, 세트, 반복, 운동 당시 느낌
- 처음 20개 표시
- `더 보기`를 누르면 20개씩 추가
- 기록 선택 시 기존 날짜별 운동 상세 바텀시트를 연다

## 빈 상태와 예외 처리

- 해당 운동 기록이 전혀 없으면 `아직 분석할 기록이 없어요` 표시
- 최근 기록이 1개뿐이어도 그래프는 1개 지점으로 표시
- 잘못된 운동 ID로 진입하면 리포트 화면으로 돌아갈 수 있는 안내 제공
- 삭제된 사용자 운동은 과거 이름 유지
- 그래프는 외부 차트 라이브러리 없이 SVG로 구현
- 모바일에서 가로 스크롤 없이 한 화면 너비에 맞춤
- 날짜 파싱이 실패한 기록은 목록 맨 아래로 보냄
- 미래 날짜 기록도 저장된 값 그대로 정렬하고 집계

## 상태 유지

운동 상세 화면은 리포트의 주간·월간 선택과 현재 기간 상태를 파괴하지 않는다. 상세 화면을 닫거나 뒤로가면 이전 리포트 위치로 복귀한다.

## 테스트 범위

- 운동일과 기록 횟수 구분
- 같은 날짜의 여러 수행 기록 처리
- 최고 중량, 최장 시간, 최다 반복 계산
- 대표 그래프 지표 자동 선택
- 최근 4회 최신순 선택
- 삭제된 사용자 운동 이름 유지
- 전체 기록 20개 단위 더 보기
- 빈 기록 화면
- 운동명 클릭 진입
- 뒤로가기 후 리포트 상태 유지
- 전체 기록에서 날짜 상세 바텀시트 열기
- 모바일 폭에서 그래프와 카드 오버플로 방지

## 구현 원칙

- 기존 `workoutLogs`를 단일 데이터 소스로 유지한다.
- 분석 통계를 localStorage에 중복 저장하지 않는다.
- 기존 날짜 상세 바텀시트를 재사용한다.
- 기존 오늘 활동, 운동 리포트, 연속 보상 기능을 변경하지 않는다.
- 이번 범위 밖 기능은 추가하지 않는다.
