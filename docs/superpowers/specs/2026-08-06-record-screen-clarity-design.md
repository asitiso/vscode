# Record Screen Clarity Design

## Goal
운동 기록 화면의 기능과 정보 순서는 유지하면서 배경·카드·텍스트·선택 상태를 명확히 분리해 선명도를 높인다.

## Scope
- 대상: `src/screens/RecordScreen.css`
- 필요 시 구조 확인만 위해 `src/screens/RecordScreen.tsx`를 참조한다.
- 운동 선택, 기록 저장, 입력 데이터, 화면 이동 로직은 변경하지 않는다.

## Visual Direction
1. 배경 이미지는 장식 수준으로 약화한다.
2. 실제 조작 영역은 완전한 흰색 카드로 표시한다.
3. 제목·본문·보조 문구를 세 단계 명도로 정리한다.
4. 선택된 항목은 진한 보라색 채움과 흰색 글자로 즉시 구분한다.
5. 그룹마다 카드 경계와 간격을 부여한다.
6. 하단 행동 영역은 불투명한 별도 바처럼 분리한다.

## Rollback Strategy
- 변경 전 브랜치: `backup/record-screen-before-clarity-update-20260806`
- 변경은 기록 화면 스타일 파일 중심의 독립 커밋으로 유지한다.
- 문제가 있으면 구현 커밋을 되돌리거나 백업 브랜치의 `RecordScreen.css`를 복원한다.

## Acceptance Criteria
- 배경 그림이 글자와 버튼 인식을 방해하지 않는다.
- 모든 입력·선택 영역이 불투명하게 보인다.
- 제목과 설명의 시각적 우선순위가 즉시 구분된다.
- 선택된 칩과 느낌 버튼이 한눈에 식별된다.
- 하단 버튼 영역과 앱 내비게이션이 겹쳐 보이지 않는다.
- 기존 기록 기능과 모바일 키보드 대응은 유지된다.
