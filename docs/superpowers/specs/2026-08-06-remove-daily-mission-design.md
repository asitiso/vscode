# 오늘의 미션 완전 제거 설계

## 목표

홈과 운동 기록 흐름에서 역할이 겹치는 `오늘의 미션` 기능을 완전히 제거해 사용자가 별도 선택 과정 없이 바로 운동 기록을 시작하도록 한다.

## 범위

### 제거 대상

- 홈 화면의 오늘의 미션 카드
- 오늘의 미션 선택 바텀시트 또는 선택 화면
- 미션 선택 여부에 따른 운동 기록 진입 제한
- 미션 선택일, 선택 카드, 완료 여부 등 미션 전용 상태
- 미션 완료 시에만 지급되는 추가 보상
- 미션 전용 문구, 스타일, 이미지, 테스트
- 미션 전용 상태 변경 액션과 파생 선택자

### 유지 대상

- 일반 운동 기록 기능
- 운동 완료 기본 보상
- 카드팩 획득 및 개봉
- 업적
- 도감
- 카드 세트 완성 보상
- 주간·월간 리포트
- 운동별 상세 분석
- 화면 안정화 기능

## 사용자 흐름

### 기존

1. 사용자가 오늘의 미션을 선택한다.
2. 미션이 선택된 상태에서 운동 기록 화면으로 이동한다.
3. 운동을 완료하면 기본 보상과 미션 전용 추가 보상을 받는다.

### 변경 후

1. 사용자가 홈 또는 하단 내비게이션의 `기록`을 누른다.
2. 즉시 운동 기록 화면으로 이동한다.
3. 운동 완료 시 기존 기본 보상만 받는다.

## 홈 화면

- 오늘의 미션 카드와 관련 CTA를 제거한다.
- 제거로 생긴 공간에 새 기능을 추가하지 않는다.
- 기존 홈 요소의 간격과 높이만 자연스럽게 재조정한다.
- 카드팩, 도감 진행률, 캐릭터, 운동 기록 CTA 등 기존 핵심 요소는 유지한다.

## 앱 내비게이션

- `canSelectDailyMission` 또는 유사 상태를 이용한 기록 탭 차단 로직을 제거한다.
- 하단 내비게이션에서 `기록` 선택 시 항상 운동 기록 화면으로 이동한다.
- 미션 선택 화면으로 우회하거나 홈으로 되돌리는 분기 로직을 제거한다.

## 상태와 저장 데이터

- 신규 상태 구조에서는 미션 전용 필드를 제거한다.
- 기존 localStorage 또는 저장 상태에 미션 필드가 남아 있어도 역직렬화 과정에서 무시한다.
- 기존 사용자 운동 기록, 카드, 코인, 업적, 도감 데이터는 유지한다.
- 마이그레이션은 미션 필드 삭제 외 다른 사용자 데이터를 수정하지 않는다.

## 보상

- 미션 완료 전용 추가 보상만 제거한다.
- 일반 운동 완료 보상 계산은 변경하지 않는다.
- 카드팩, 업적, 세트 완성 등 다른 보상 체계는 변경하지 않는다.
- 미션 제거로 인해 일반 보상을 상향하거나 대체 보상을 추가하지 않는다.

## 코드 정리

- 미션 전용 컴포넌트와 스타일 파일은 참조가 완전히 사라지면 삭제한다.
- 미션 전용 타입, 상수, 유틸리티, 액션, 리듀서 분기를 제거한다.
- 미션 관련 import, 조건문, 테스트 fixture를 정리한다.
- 다른 기능과 공유하는 코드는 유지하고 미션 전용 부분만 제거한다.

## 오류 방지

- 미션 필드가 포함된 과거 저장 데이터로 앱을 실행해도 오류가 발생하지 않아야 한다.
- 미션 제거 후 기록 화면 진입이 항상 가능해야 한다.
- 운동 완료 보상, 카드팩, 업적, 도감 상태가 기존과 동일하게 갱신돼야 한다.
- 홈 화면에서 빈 영역, 겹침, 비정상 여백이 없어야 한다.

## 테스트 기준

- 홈에서 오늘의 미션 관련 문구와 버튼이 렌더링되지 않는다.
- 하단 내비게이션의 `기록` 버튼을 누르면 즉시 기록 화면으로 이동한다.
- 미션 상태가 없는 초기 데이터로 앱이 정상 렌더링된다.
- 미션 상태가 포함된 과거 저장 데이터도 정상 로드된다.
- 운동 완료 시 기본 보상은 지급되고 미션 전용 추가 보상은 지급되지 않는다.
- 카드팩, 업적, 도감, 리포트 기능에 회귀가 없다.
- `npm test`와 `npm run build`가 통과해야 한다.

## 제외 범위

- 일반 운동 완료 보상 재설계
- 카드팩 확률 또는 보상량 조정
- 홈 화면 신규 기능 추가
- 업적, 도감, 리포트 구조 변경
- 전체 상태 저장 구조 개편
- PR 병합

## 완료 조건

- 앱 전체에서 오늘의 미션 관련 UI와 문구가 보이지 않는다.
- 사용자가 미션 선택 없이 바로 운동 기록을 시작할 수 있다.
- 미션 전용 상태와 추가 보상 로직이 제거된다.
- 기존 저장 데이터가 안전하게 로드된다.
- 다른 보상과 기록 기능은 기존 동작을 유지한다.
