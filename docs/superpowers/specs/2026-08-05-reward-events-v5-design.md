# 보상 이벤트 5차 통합 설계

## 목표

5차 업데이트는 보상 개봉 연출을 더 길게 만드는 것이 아니라, 반복 개봉에서도 같은 장면이 계속 반복되는 느낌을 줄이고 중복 카드도 성장 보상으로 받아들이게 만드는 데 목적이 있다.

핵심은 두 축이다.

1. 반복 재미 강화: 개봉 대사, 움직임, 예고, 사운드가 여러 패턴으로 변한다.
2. 성장 재미 강화: 카드 공개 뒤 현재 성장 상태와 다음 목표를 즉시 이해할 수 있다.

카드 확률, 카드 선택, 지급 수량, 도감 저장 구조, 별 성장 기준은 변경하지 않는다.

## 사용자 흐름

`개봉 패턴 선택 → 카드팩 조작 → 희귀 예고 → 카드 공개 → 성장 진행 → 추가 보상 → 최종 피날레`

일반 카드와 성장 변화가 없는 중복 카드는 빠르게 진행한다. 희귀 카드, 별 성장, 진화 해금이 발생할 때만 강조 연출을 추가한다. 기본 흐름은 약 4~6초 안에 끝나도록 유지한다.

## 1. 개봉 변주 시스템

### 패턴 구성

개봉 시 다음 세 가지 패턴 중 하나를 선택한다.

- `pulse`: 카드팩이 심장박동처럼 커졌다 작아지며 빛이 모인다.
- `spin`: 카드팩이 살짝 회전하고 링이 빠르게 감긴다.
- `shake`: 카드팩이 좌우로 흔들리며 에너지가 불안정하게 튄다.

각 패턴은 CSS 클래스와 사운드 프리셋으로 분리한다. 카드 보상 결과에는 영향을 주지 않는다.

### 반복 방지

최근 사용한 패턴 id를 `sessionStorage`에 저장한다. 다음 개봉에서는 같은 패턴을 제외한 후보 중 하나를 선택한다. 브라우저 탭을 닫으면 기록은 초기화된다.

### 대사 변주

개봉 전, 충전 중, 공개 직전 문구를 각각 5개 이상 준비한다. 현재 패턴과 카드팩 종류를 이용해 문구를 선택하되 보상 등급을 미리 노출하지 않는다.

예시:

- 개봉 전: `오늘의 운동 에너지가 도착했어요`, `새로운 친구가 기다리고 있어요`
- 충전 중: `힘이 모이고 있어요`, `한 번 더 밀어주세요`
- 공개 직전: `무언가 특별한 기운이 느껴져요`, `카드가 깨어납니다`

### 희귀 예고

보상 결과가 레어 이상일 때 공개 직전에 등급별 예고 강도를 다르게 적용한다.

- 레어: 파란 빛이 잠깐 스친다.
- 슈퍼 레어: 보라색 글리치와 이중 링이 나타난다.
- 레전드: 기존 전용 시네마틱으로 연결한다.

이 예고는 결과가 이미 내부적으로 결정된 뒤 표시하며 확률이나 결과를 변경하지 않는다.

## 2. 성장 진행 시스템

### 다음 성장 계산

현재 카드 수를 기준으로 다음 별 기준을 계산한다.

- 1성에서 2성: 총 2장
- 2성에서 3성: 총 5장
- 3성에서 4성: 총 10장
- 4성: 최대 성장

표시 정보:

- 현재 카드 수
- 현재 별 단계
- 다음 별까지 남은 장수
- 다음 별 기준 진행률

예시: `3성까지 2장 남았어요 · 3/5`

### 성장 게이지

카드 공개 결과 아래에 성장 게이지를 표시한다. 이번 카드 획득 전 진행률에서 현재 진행률까지 애니메이션으로 상승한다.

별 단계가 실제로 상승한 경우 게이지가 가득 찬 뒤 `STAR UP` 연출로 연결한다. 4성에 도달한 경우 `MAX` 상태와 특별 일러스트 해금 여부를 표시한다.

### 중복 카드 메시지

중복 카드에서는 `또 나왔어요` 같은 실패 표현을 사용하지 않는다.

상태별 문구:

- 성장 기준 미도달: `성장 에너지가 쌓였어요`
- 별 상승: `새로운 별이 켜졌어요`
- 4성 도달: `최대 성장에 도달했어요`
- 진화 일러스트 존재: `특별 일러스트가 해금됐어요`

## 3. 최종 피날레 개선

기존 피날레에 다음 성장 목표를 추가한다.

- 신규 카드: 도감에 새로 채워졌다는 문구
- 성장 중: 다음 별까지 남은 장수
- 별 상승: 이번에 상승한 단계
- 최대 성장: `MAX` 및 진화 일러스트 상태

피날레의 다시보기는 시각·사운드 연출만 다시 실행하며 `openPack`을 다시 호출하지 않는다.

## 4. 사운드 변주

기존 Web Audio 엔진을 유지한다. 패턴별로 음정, 재생 간격, 파형을 조금씩 바꾼다.

- `pulse`: 낮은 두 번의 펄스
- `spin`: 상승하는 짧은 음계
- `shake`: 짧게 끊기는 진동음

희귀 예고와 성장 게이지 완료에도 각각 짧은 신호음을 추가한다. 사용자 소리 설정과 브라우저 자동재생 제한을 그대로 따른다.

## 5. 컴포넌트 경계

`PackOpeningScreen.tsx`가 지나치게 커지지 않도록 계산과 패턴 정의를 분리한다.

- `rewardOpeningVariants.ts`: 패턴 목록, 문구 목록, 다음 패턴 선택
- `cardGrowth.ts`: 다음 별 기준, 남은 장수, 진행률 계산
- `RewardGrowthProgress.tsx`: 성장 게이지와 목표 표시
- `RewardEventsV5.css`: 5차 패턴 및 성장 애니메이션

기존 1~4차 화면 구조와 상태 흐름은 유지한다.

## 6. 오류 및 경계 처리

- 카드 결과가 아직 상태에 반영되지 않았으면 기존 충전·공개 대기 흐름을 유지한다.
- 저장 데이터가 오래되어 카드 수가 0이거나 잘못된 값이면 0 이상으로 보정한다.
- 최대 성장 카드에서는 다음 목표를 계산하지 않고 `MAX`로 표시한다.
- `sessionStorage` 접근이 차단된 환경에서는 메모리 기반 무작위 선택으로 폴백한다.
- 동작 감소 설정에서는 흔들림, 회전, 글리치 애니메이션을 제거하고 페이드만 사용한다.

## 7. 검증 항목

1. 같은 탭에서 연속 두 번 개봉했을 때 동일 패턴이 반복되지 않는다.
2. 패턴 차이는 시각과 사운드에만 영향을 주고 카드 결과에는 영향을 주지 않는다.
3. 카드 수 1, 2, 4, 5, 9, 10장에서 다음 성장 목표가 정확하다.
4. 중복 카드 획득 전후 성장 게이지가 올바르게 움직인다.
5. 2장, 5장, 10장 도달 시 별 상승 연출이 나타난다.
6. 4성 카드에서는 다음 목표 대신 `MAX`가 표시된다.
7. 다시보기로 보상이 중복 지급되지 않는다.
8. 소리 끄기와 동작 감소 설정이 5차 효과에도 적용된다.
9. 375px, 390px, 430px 모바일 너비에서 버튼과 성장 정보가 잘리지 않는다.

## 제외 범위

- 카드 확률 변경
- 새 카드나 새 카드팩 데이터 추가
- 실제 보너스 카드 추가 지급
- 서버 저장 또는 계정 동기화
- 시즌 일정 관리 시스템
- 카드별 능력치나 전투 시스템
