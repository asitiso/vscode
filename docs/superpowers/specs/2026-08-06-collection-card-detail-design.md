# 카드 도감 카드 확대 및 상세 팝업 설계

## 1. 목적

현재 카드 도감은 3:4 비율의 카드 칸을 사용하지만, 실제 일러스트가 내부에서 작은 아이콘처럼 보여 수집 카드의 존재감이 약하다. 또한 카드가 클릭 가능한 구조가 아니어서 획득한 카드의 설명, 등급, 별 레벨, 소속 세트를 확인할 수 없다.

이번 작업은 기존 도감의 필터, 데이터, 수집 진행률, 카드 획득 로직을 유지하면서 다음 경험을 추가한다.

- 카드 칸에 맞춰 일러스트를 크게 표시한다.
- 등급별 프레임과 하단 정보 띠를 적용해 수집 카드처럼 보이게 한다.
- 획득 여부와 관계없이 모든 카드를 클릭할 수 있게 한다.
- 획득 카드는 상세 정보를 보여 주는 모달을 연다.
- 미획득 카드는 실제 정보를 노출하지 않고 발견 안내만 보여 준다.

## 2. 범위

### 포함

- 도감 카드 렌더링을 클릭 가능한 버튼 컴포넌트로 분리
- 카드 이미지 영역과 하단 이름 영역 분리
- 카드 이미지 확대 및 원본 비율 유지
- 등급별 프레임 스타일
- 획득 카드 상세 모달
- 미획득 카드 잠금 상태 및 안내 모달
- 키보드와 스크린리더를 고려한 기본 접근성
- 관련 상호작용 테스트

### 제외

- 카드 획득 확률 또는 보상 로직 변경
- 카드 세트 구조 변경
- 카드 능력치, 판매, 분해, 공유 기능
- 획득 날짜 표시
- 카드 진화 트리
- 음성, 3D 회전, 지속 애니메이션
- 별도 상세 페이지 라우팅
- 도감 열 수 또는 필터 구조 변경

## 3. 기존 구조와 유지 조건

현재 `CollectionScreen`은 다음 책임을 가진다.

- 등급 및 세트 필터 상태 관리
- `CARDS` 필터링
- `state.ownedCards[card.id]`로 획득 여부 확인
- `pickDisplayIllustration(card, owned.starLevel)`로 획득 카드 이미지 선택
- 카드 세트 진행률과 완성률 표시

이번 변경에서도 위 데이터 흐름과 필터 동작은 유지한다. 카드 선택 상태와 모달 열기/닫기만 `CollectionScreen`에 추가한다.

`CardDefinition`에는 이미 `description: string`이 있으므로 카드 설명을 위해 타입이나 카드 데이터 스키마를 새로 확장하지 않는다.

## 4. 컴포넌트 구조

```text
src/screens/CollectionScreen.tsx
src/screens/CollectionScreen.css
src/screens/CollectionCard.tsx
src/screens/CollectionCardDetailModal.tsx
src/screens/CollectionCardDetailModal.css
```

### `CollectionScreen`

책임:

- 기존 세트 및 등급 필터 유지
- 필터링된 카드 목록 계산
- 선택된 카드 ID 관리
- 선택 카드와 획득 상태 계산
- 상세 모달 열기와 닫기

추가 상태:

```ts
const [selectedCardId, setSelectedCardId] = useState<string | null>(null);
```

선택 카드는 `CARDS.find`로 조회한다. 카드가 필터 변경으로 화면에서 사라져도 이미 열린 모달은 사용자가 닫을 때까지 유지할 수 있다.

### `CollectionCard`

책임:

- 카드 한 장의 획득/미획득 표시
- 등급별 프레임 적용
- 일러스트와 하단 정보 띠 렌더링
- 클릭 이벤트 전달

권장 props:

```ts
interface CollectionCardProps {
  card: CardDefinition;
  owned?: OwnedCard;
  onSelect: (cardId: string) => void;
}
```

루트는 `div`가 아니라 `button type="button"`을 사용한다. 별도 키보드 핸들러 없이 Enter와 Space 동작을 기본 제공한다.

### `CollectionCardDetailModal`

책임:

- 획득 카드 상세 정보 표시
- 미획득 카드 안내 표시
- 닫기 버튼, 배경 클릭, ESC 닫기
- 모달이 열린 동안 배경 스크롤 잠금

권장 props:

```ts
interface CollectionCardDetailModalProps {
  card: CardDefinition;
  owned?: OwnedCard;
  setName?: string;
  onClose: () => void;
}
```

기존 `useBodyScrollLock` 훅이 있다면 이를 재사용하고 새 잠금 로직을 중복 구현하지 않는다.

## 5. 도감 카드 디자인

### 전체 구조

```text
┌──────────────┐
│ 등급 배지     │
│              │
│   카드 이미지 │
│              │
│──────────────│
│ 카드 이름  ★★ │
└──────────────┘
```

### 카드 비율과 이미지

- 기존 `aspect-ratio: 3 / 4` 유지
- 상단 이미지 영역은 카드 높이의 약 75~78%
- 하단 정보 띠는 약 22~25%
- 일러스트는 `object-fit: contain`
- 원본 비율을 유지하고 잘라내지 않음
- 투명 PNG가 프레임 안에서 최대한 크게 보이도록 이미지 영역 내부 여백 최소화
- `PlaceholderArt`가 이미지 크기를 제한한다면 카드 전용 class 또는 prop을 추가해 카드 영역을 충분히 채우게 함

### 하단 정보 띠

획득 카드:

- 불투명 배경
- 카드 이름 한 줄
- 긴 이름은 말줄임
- 우측에 현재 별 레벨 표시

미획득 카드:

- 이름 대신 `미발견`
- 별 표시 없음
- 실제 이름을 DOM과 접근성 레이블에도 넣지 않음

### 등급 프레임

- 일반: 회색 또는 민트 계열의 차분한 프레임
- 레어: 파란 프레임과 약한 푸른 광택
- 슈퍼 레어: 보라 계열 그라데이션과 정적인 대각선 하이라이트
- 레전드: 금색 프레임과 은은한 반짝임 표현

등급 효과는 카드 식별을 돕는 수준으로 제한한다. 지속 회전, 큰 흔들림, 반복 점멸은 사용하지 않는다.

### 상호작용

- hover 가능한 환경: 약간 위로 이동하거나 1.02배 확대
- active: 눌림 피드백
- focus-visible: 명확한 포커스 링
- `prefers-reduced-motion`에서는 이동 및 확대를 최소화

## 6. 미획득 카드 정보 보호

사용자가 선택한 옵션 2를 적용한다.

### 도감 목록

- 모든 카드 클릭 가능
- 회색 또는 저채도 배경
- 일러스트는 실루엣 또는 `?`
- 이름은 `미발견`
- 등급 배지 숨김
- 별 숨김
- 잠금 아이콘 표시 가능

### 상세 모달

표시 문구:

```text
아직 발견하지 못한 카드입니다

운동을 기록하고 보상을 받아
새로운 카드를 발견해 보세요.
```

숨기는 정보:

- 실제 카드 이름
- 등급
- 설명
- 카드 세트
- 진화 이미지

미획득 카드의 실제 정보는 화면에 보이지 않는 것뿐 아니라 `aria-label`, `title`, 대체 텍스트 등에도 노출하지 않는다. 버튼의 접근성 이름은 `미발견 카드 자세히 보기`처럼 일반화한다.

## 7. 획득 카드 상세 모달

### 표시 정보

- 큰 카드 이미지
- 카드 이름
- 등급
- 현재 별 레벨
- 소속 카드 세트
- 카드 설명
- 획득 상태
- 최대 별 여부

최대 별은 `owned.starLevel === 4`로 판단한다. 최대 별이 아니면 별 레벨만 표시하고 다음 진화 조건이나 필요한 중복 횟수는 이번 범위에 넣지 않는다.

### 세트 조회

기존 `findSetForCard(card.id)`를 사용해 소속 세트를 조회한다. 세트가 없는 예외 상황에서는 세트 행을 숨기거나 `세트 없음`으로 표시하되 오류를 발생시키지 않는다.

### 이미지 선택

획득 카드 모달에서도 목록과 동일하게 다음 함수를 사용한다.

```ts
pickDisplayIllustration(card, owned.starLevel)
```

별 4개이며 진화 이미지가 있는 경우 진화 이미지를 표시한다.

## 8. 모달 동작과 접근성

- 카드 클릭으로 열기
- X 버튼으로 닫기
- 모달 바깥 배경 클릭으로 닫기
- 모달 본문 클릭은 닫힘 방지
- ESC 키로 닫기
- 모달 열린 동안 배경 스크롤 잠금
- `role="dialog"`
- `aria-modal="true"`
- 제목 요소를 `aria-labelledby`로 연결
- 닫기 버튼에 명확한 `aria-label`
- 모달이 닫힌 뒤 가능하면 이전에 선택한 카드 버튼으로 포커스 복귀

포커스 트랩은 기존 프로젝트에 재사용 가능한 구현이 있을 때만 사용한다. 별도 라이브러리 도입은 이번 범위에서 제외한다. 최소 요구는 모달이 열릴 때 닫기 버튼 또는 제목 영역으로 포커스를 이동하고, 닫을 때 원래 카드로 복귀하는 것이다.

## 9. 데이터 흐름

```text
CollectionScreen
  ├─ filteredCards 계산
  ├─ ownedCards에서 획득 상태 조회
  ├─ CollectionCard에 card/owned 전달
  └─ 카드 선택 시 selectedCardId 저장
        └─ 선택 카드와 owned 조회
             └─ CollectionCardDetailModal 렌더링
```

모달은 게임 상태를 수정하지 않는다. 읽기 전용 UI이며 닫기 외의 액션은 없다.

## 10. 오류 및 예외 처리

- 선택된 카드 ID가 `CARDS`에 없으면 모달을 렌더링하지 않음
- 카드에 세트가 없으면 세트 정보 행을 생략
- 이미지 자산을 찾지 못하면 기존 `PlaceholderArt` fallback 사용
- `ownedCards`에 항목이 없으면 항상 미획득 상태로 처리
- 설명이 빈 문자열인 경우 빈 영역을 만들지 않고 기본 안내 문구를 표시할 수 있으나, 카드 데이터 자체는 이번 작업에서 임의로 변경하지 않음

## 11. 테스트 계획

### `CollectionCard`

- 획득 카드는 실제 이름과 별 레벨을 표시
- 미획득 카드는 `미발견`만 표시
- 미획득 카드에서 실제 이름, 등급 텍스트가 노출되지 않음
- 클릭 시 카드 ID를 전달
- 루트 요소가 버튼이며 키보드로 실행 가능

### `CollectionCardDetailModal`

- 획득 카드의 이름, 등급, 설명, 세트, 별 레벨 표시
- 별 4개 카드에서 최대 별 상태 표시
- 미획득 카드에서 발견 안내만 표시
- 미획득 카드의 실제 이름, 등급, 설명, 세트가 노출되지 않음
- X 버튼으로 닫힘
- 배경 클릭으로 닫힘
- 본문 클릭은 닫히지 않음
- ESC로 닫힘
- dialog 접근성 속성 존재

### `CollectionScreen`

- 카드 클릭 시 해당 상세 모달 열림
- 모달 닫기 후 화면 복귀
- 기존 등급 및 세트 필터가 유지됨

## 13. 완료 조건

- 카드 이미지가 기존보다 명확히 커져 카드 프레임의 주 시각 요소가 됨
- 획득 카드가 등급별 수집 카드처럼 구분됨
- 모든 카드가 버튼으로 클릭 가능
- 획득 카드 상세 모달에서 요구 정보 확인 가능
- 미획득 카드의 실제 정보가 목록과 모달 및 접근성 텍스트에서 숨겨짐
- X, 배경 클릭, ESC로 모달 닫기 가능
- 배경 스크롤 잠금과 포커스 복귀 동작
- 기존 필터, 카드 세트 진행률, 획득 데이터, 보상 로직에 회귀 없음
- 관련 테스트와 빌드를 실행한 뒤 실제 결과만 보고
- PR #14에 반영하되 병합하지 않음
