# 오늘의 카드 미션 설계

## 목표

사용자가 매일 앱에 들어와 오늘의 운동 목표를 직접 선택하고, 운동 기록만으로 미션을 완료해 보너스팩을 받도록 한다.

핵심 루프는 다음과 같다.

`홈 진입 → 오늘의 미션 3개 확인 → 1개 선택 → 운동 기록 → 조건 자동 판정 → 보너스팩 자동 지급`

이번 업데이트는 새로운 재화나 새 탭을 만들지 않고 기존 홈, 운동 기록, 카드팩 개봉 흐름을 재사용한다.

## 확정된 원칙

- 홈에서 오늘의 미션 3개 중 하나를 직접 선택한다.
- 미션은 쉬움·보통·어려움 1개씩 제공한다.
- 선택 후 당일에는 변경할 수 없다.
- 첫 운동 기록을 시작하기 전에만 선택할 수 있다.
- `오늘 운동 기록하기`를 누르면 홈 위에 바텀시트가 열린다.
- 미션을 선택해야 기록 화면으로 이동할 수 있다.
- 모든 미션 보상은 동일한 미션 보너스팩 1개다.
- 조건 달성 시 미션은 자동 완료되고 보너스팩도 즉시 지급된다.
- 미션은 카테고리 중심으로만 구성하며 특정 운동기구 하나를 강요하지 않는다.
- 최근 14일 기록을 반영해 익숙한 카테고리 2개와 도전형 1개를 생성한다.
- 하루 동안 여러 번 기록한 운동은 합산해 완료 여부를 판정한다.
- 새로운 재화, 미션 전용 탭, 수동 보상 수령 버튼은 만들지 않는다.

## 매일 생성되는 미션 3개

### 쉬움

최근 14일 동안 가장 자주 기록한 카테고리에서 서로 다른 운동 1종을 기록한다.

예:

- 유산소 운동 1종 기록
- 하체 운동 1종 기록
- 등 운동 1종 기록

완료 조건:

- 선택한 날짜의 운동 기록에 해당 카테고리 운동 ID가 하나 이상 포함된다.
- 시간, 무게, 횟수, 세트의 최소값은 별도로 두지 않는다.

### 보통

최근 14일 동안 두 번째로 자주 기록한 카테고리에서 서로 다른 운동 2종을 기록한다.

예:

- 하체 운동 2종 기록
- 가슴 운동 2종 기록
- 유산소 운동 2종 기록

완료 조건:

- 같은 날짜에 기록한 해당 카테고리의 서로 다른 운동 ID가 2개 이상이다.
- 같은 운동을 여러 번 기록해도 1종으로 계산한다.
- 사용자 직접 입력 운동은 `기타` 카테고리 미션에서만 해당 카테고리 운동으로 계산한다.

### 어려움

오늘의 집중 세트에 연결된 서로 다른 운동 2종을 기록한다.

예:

- 오늘의 하체 머신 세트 운동 2종 기록
- 오늘의 등 당기기 세트 운동 2종 기록

완료 조건:

- 오늘의 집중 세트에 속한 카드 4장의 `exerciseId` 중 서로 다른 운동 2종을 기록한다.
- 해당 카드를 이미 보유했는지는 완료 조건에 영향을 주지 않는다.
- 사용자 직접 입력 운동은 카드 세트와 연결되지 않으므로 어려움 미션에 포함하지 않는다.

## 최근 14일 기록 분석

카테고리 빈도는 오늘을 제외한 최근 14개의 로컬 날짜 범위에서 계산한다.

- 한 운동 기록에 같은 카테고리 운동이 여러 종 있어도 각 서로 다른 운동 ID를 빈도에 반영한다.
- 사용자 직접 입력 운동은 `etc` 카테고리로 반영한다.
- 가장 빈도가 높은 카테고리를 쉬움 후보로 사용한다.
- 두 번째로 높은 서로 다른 카테고리를 보통 후보로 사용한다.
- 빈도가 같으면 고정된 카테고리 순서를 사용해 결과를 결정적으로 만든다.
- 같은 날짜와 같은 기록 상태에서는 새로고침해도 동일한 미션 3개가 생성되어야 한다.

## 신규 사용자와 기록 부족 처리

최근 14일 운동 기록이 2회 미만이거나 서로 다른 카테고리를 2개 확보하지 못하면 기본 후보로 보충한다.

기본 미션:

- 쉬움: 유산소 운동 1종 기록
- 보통: 카테고리 제한 없이 서로 다른 기본 운동 2종 기록
- 어려움: 오늘의 집중 세트 운동 2종 기록

보통 기본 미션은 사용자 직접 입력 운동도 서로 다른 운동 ID라면 포함한다. 단, 같은 운동 ID 반복은 1종으로 계산한다.

## 중복과 생성 안전 규칙

- 쉬움과 보통은 서로 다른 카테고리를 사용한다.
- 어려움 미션의 오늘의 세트가 쉬움 또는 보통 카테고리와 겹치는 것은 허용한다.
- 같은 문구와 같은 조건의 미션을 한 날짜에 두 번 만들지 않는다.
- 생성 결과는 `easy`, `normal`, `hard` 세 난이도를 정확히 하나씩 포함해야 한다.
- 오늘의 집중 세트 계산은 기존 카드 세트 컬렉션의 순수 함수를 재사용한다.

## 미션 선택 흐름

홈에서 `오늘 운동 기록하기`를 누르면 다음과 같이 동작한다.

1. 오늘 선택된 미션이 없고 오늘 운동 기록도 없다면 미션 바텀시트를 연다.
2. 바텀시트에 쉬움·보통·어려움 미션 카드 3개를 표시한다.
3. 각 카드에는 난이도, 미션 문구, 조건 요약, `보너스팩 1개`를 표시한다.
4. 사용자가 하나를 선택하면 선택 상태를 저장한다.
5. 바텀시트를 닫고 운동 기록 화면으로 이동한다.

이미 오늘 미션을 선택한 경우에는 바텀시트를 다시 열지 않고 바로 기록 화면으로 이동한다.

오늘 운동 기록이 이미 존재하지만 미션 선택 상태가 없는 이전 데이터 또는 예외 상태에서는 새 미션을 선택할 수 없다. 홈에는 `오늘은 미션 없이 기록했어요` 상태를 표시하고 일반 기록은 계속 허용한다.

## 선택 잠금

- 미션 선택은 오늘의 첫 운동 기록이 생성되기 전까지만 허용한다.
- 선택한 뒤에는 당일 변경과 취소를 허용하지 않는다.
- 날짜가 바뀌면 이전 선택은 기록으로 남지만 새 날짜에는 새로운 미션을 선택할 수 있다.
- 앱을 새로고침하거나 다시 실행해도 선택 상태가 유지되어야 한다.

## 홈 화면

미션 선택 전에는 기존 홈을 유지하고, 운동 기록 버튼을 눌렀을 때만 바텀시트를 표시한다.

선택 후에는 홈에 작은 미션 진행 카드 하나를 표시한다.

예:

> 오늘의 미션 · 보통  
> 하체 운동 2종 기록  
> 1 / 2종 완료

완료 후:

> 오늘의 미션 완료!  
> 보너스팩이 도착했어요

홈이 복잡해지지 않도록 미션 3개를 상시 노출하지 않는다. 선택된 미션 1개만 카드 세트 진행 영역과 충돌하지 않는 작은 카드로 표시한다.

## 완료 판정

운동 기록 저장 직후 오늘 선택한 미션을 검사한다.

- 선택한 날짜와 같은 로컬 날짜의 모든 운동 기록을 합산한다.
- 서로 다른 운동 수는 `exerciseId` 기준으로 계산한다.
- 카테고리 미션은 기본 운동 정의와 사용자 운동 스냅샷 또는 현재 사용자 운동 정의를 통해 카테고리를 해석한다.
- 삭제된 사용자 운동은 기록 당시 `exerciseName`은 유지되지만 카테고리는 항상 `etc`로 취급한다.
- 조건을 처음 충족한 순간 `completedAt`을 저장하고 미션 보너스팩 1개를 생성한다.
- 이미 `completedAt` 또는 `rewardPackId`가 있는 미션에는 다시 보상을 지급하지 않는다.

## 미션 보너스팩

기존 `GrantedPack`과 카드 개봉 화면을 재사용한다.

권장 확률:

- 일반 50%
- 레어 35%
- 슈퍼레어 13%
- 레전더리 2%

보상 위계:

`일반 운동팩 < 미션 보너스팩 < 세트 완성 특별상자`

추가 규칙:

- 기존 레전더리 천장 카운터에 정상 반영한다.
- 기존 중복 성장과 별 단계 규칙을 그대로 사용한다.
- 미션 종류에 따른 카드 카테고리 가중치는 첫 버전에서 적용하지 않는다.
- 오늘의 세트 보너스는 일반 카드 개봉 규칙과 동일하게 적용할 수 있으나 세트 완성 특별상자보다 우선하지 않는다.
- `GrantedPack.source`에 `daily-mission`을 추가하고 해당 미션 인스턴스 ID를 선택 필드로 저장한다.

## 저장 상태

날짜별 미션 상태를 보존하기 위해 다음 구조를 추가한다.

```ts
interface DailyMissionOption {
  id: string;
  difficulty: 'easy' | 'normal' | 'hard';
  kind: 'category-count' | 'any-exercise-count' | 'featured-set-count';
  label: string;
  targetCount: number;
  category?: ExerciseCategory;
  setId?: string;
}

interface DailyMissionState {
  date: string;
  options: DailyMissionOption[];
  selectedMissionId?: string;
  selectedAt?: string;
  completedAt?: string;
  rewardPackId?: string;
}
```

`AppState`에는 최근 날짜의 상태를 보존할 수 있도록 `dailyMissions: Record<string, DailyMissionState>`를 추가한다.

첫 버전에서는 오래된 기록을 자동 삭제하지 않는다. 데이터 크기가 문제가 될 정도로 커지지 않으며, 과거 미션 이력을 추후 통계에 활용할 수 있다.

기존 저장 데이터에 `dailyMissions`가 없으면 빈 객체로 마이그레이션한다.

기존 팩의 `source` 값은 현재 규칙대로 `workout`으로 간주한다.

## 바텀시트 접근성과 동작

- 바텀시트는 `role="dialog"`와 제목 연결을 제공한다.
- 배경 영역을 눌러 닫을 수 있지만 닫은 경우 기록 화면으로 이동하지 않는다.
- ESC 키로 닫을 수 있다.
- 미션 선택 버튼은 키보드와 터치 모두 사용할 수 있어야 한다.
- 선택 직후 중복 탭이 발생해도 하나의 미션만 저장되어야 한다.
- 선택 저장에 실패하면 바텀시트를 유지하고 기록 화면으로 이동하지 않는다.

## 오류와 안전 처리

- 저장된 선택 미션 ID가 오늘의 옵션에 없으면 미션 미선택 상태로 복구하되 이미 오늘 기록이 있으면 재선택을 막는다.
- 저장된 미션의 카테고리 또는 세트 ID가 더 이상 유효하지 않으면 완료 판정을 하지 않고 개발 경고를 남긴다.
- 오늘의 세트 정의가 비어 있으면 어려움 미션 대신 `서로 다른 운동 3종 기록`으로 폴백한다.
- 미션 보너스팩 생성 도중 같은 액션이 반복되어도 `rewardPackId` 기준으로 중복 지급을 막는다.
- 날짜 계산은 사용자의 로컬 날짜 `YYYY-MM-DD`를 사용한다.

## 테스트 범위

### 생성 로직

- 최근 14일 최다·차다 카테고리를 올바르게 선택한다.
- 기록이 부족하면 기본 미션으로 보충한다.
- 세 난이도가 하나씩 생성된다.
- 같은 날짜와 같은 상태에서 결과가 동일하다.
- 쉬움과 보통 카테고리가 겹치지 않는다.

### 선택 로직

- 미션 선택 전 바텀시트가 열린다.
- 선택하면 저장 후 기록 화면으로 이동한다.
- 선택 후 같은 날짜에는 변경할 수 없다.
- 첫 운동 기록 후 미선택 상태에서는 새 미션을 선택할 수 없다.

### 완료 로직

- 하루 여러 기록을 합산한다.
- 같은 운동 반복은 한 종으로 계산한다.
- 사용자 운동은 `etc` 미션과 전체 운동 수 미션에 반영된다.
- 오늘의 세트 운동 2종을 기록하면 어려움 미션이 완료된다.
- 완료 시 보너스팩이 정확히 한 번 지급된다.
- 새로고침 후에도 중복 지급되지 않는다.

### 팩 개봉

- 미션 보너스팩은 지정된 확률표를 사용한다.
- 천장과 중복 성장 규칙이 유지된다.
- 세트 완성 특별상자 확률에 영향을 주지 않는다.

### 회귀 검증

- 미션 미선택 상태에서도 기존 홈과 도감이 정상 표시된다.
- 일반 운동 기록 보상상자가 그대로 지급된다.
- 사용자 직접 입력 운동과 카드 세트 컬렉션 기능이 유지된다.
- 모바일 좁은 화면에서 바텀시트와 선택 카드가 잘리지 않는다.

## 이번 업데이트에서 제외

- 미션 변경권
- 미션 건너뛰기 또는 새로고침
- 미션별 서로 다른 보상
- 특정 운동기구 미션
- 카드 조각 또는 새로운 재화
- 연속 미션 달성 보너스
- 주간 미션
- 미션 전용 탭
- 친구 미션 또는 경쟁 기능
