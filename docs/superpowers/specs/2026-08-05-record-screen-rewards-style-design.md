# 기록 화면 보상 탭 스타일 통일 설계

## 목표

기록 탭을 보상 탭과 동일한 시각 언어로 통일한다. 운동 선택, 세트 입력, 느낌 선택, 메모, 기록 완료 기능은 그대로 유지하고 정보 구조와 스타일만 개선한다.

## 화면 구조

1. 상단 헤더
   - 영문 라벨 `TODAY WORKOUT`
   - 제목 `오늘 운동 기록`
   - 설명 `운동을 선택하고 오늘의 기록을 남겨보세요.`
2. 오늘의 운동 카드
   - 최근 운동
   - 운동 카테고리
   - 선택 가능한 운동
   - 선택된 운동 수 배지
3. 운동 기록 카드
   - 선택한 운동별 수치 입력
   - 근력 운동: 무게, 반복, 세트
   - 시간 운동: 운동 시간
4. 오늘의 느낌 카드
   - 기존 7개 느낌 옵션 유지
   - 선택 상태는 보라색 강조
5. 메모 카드
   - 기존 textarea 유지
6. 하단 작업 영역
   - 취소 / 기록 완료
   - 하단 내비게이션에 가리지 않도록 sticky 배치

## 디자인 규칙

- 배경: 보상 화면과 같은 밝고 흐린 배경 이미지
- 카드: 흰색, 22~26px 둥근 모서리, 연한 보라 테두리
- 제목: 짙은 남색
- 핵심 강조: 보라색
- 보조 강조: 주황색
- 선택 칩: 연보라 배경과 진한 보라 테두리
- 완료 버튼: 보라색 그라데이션
- 섹션 간격: 16px
- 카드 내부 여백: 16~18px

## 기능 보존

- 최근 운동 계산 방식 유지
- 운동 선택 및 해제 방식 유지
- 이전 기록 불러오기 유지
- 숫자 입력과 기록 저장 방식 유지
- 완료 가능 조건 유지: 운동 1개 이상 + 느낌 선택
- 카드팩 지급과 화면 이동 로직 변경 없음

## 접근성 및 모바일

- 모든 버튼은 최소 44px 터치 높이 확보
- 입력 필드에 기존 label 연결 유지
- 375px 폭에서 가로 스크롤 없음
- sticky 작업 버튼이 하단 내비게이션 위에 표시됨
- 비활성 완료 버튼 상태를 명확하게 구분

## 검증 기준

1. 기록 화면이 보상 탭과 같은 카드형 스타일로 보인다.
2. 최근 운동, 카테고리, 운동 선택 기능이 기존과 동일하게 동작한다.
3. 선택한 운동의 수치 입력값을 변경할 수 있다.
4. 느낌 선택과 메모 입력이 동작한다.
5. 운동과 느낌을 선택하기 전에는 완료 버튼이 비활성화된다.
6. 완료 버튼이 하단 내비게이션에 가려지지 않는다.
7. 375px, 390px, 430px 화면에서 레이아웃이 깨지지 않는다.
