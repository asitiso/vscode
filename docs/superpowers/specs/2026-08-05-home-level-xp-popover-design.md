# 홈 레벨 경험치 팝업 설계

## 목표

홈 화면의 레벨 배지를 누르면 현재 경험치, 다음 레벨에 필요한 경험치, 진행률, 남은 경험치를 작은 팝업으로 보여준다. 경험치는 새 저장 필드를 추가하지 않고 기존 운동 기록과 카드팩 개봉 이력에서 매번 계산한다.

## 경험치 계산 규칙

- 운동 기록 1회: 100 XP
- 카드팩 개봉 1회: 30 XP
- 개인 기록(`personal-best`) 운동 1회: 추가 50 XP
- 주간 목표 달성 주 1회: 추가 150 XP
- 다음 레벨 필요 경험치: `현재 레벨 × 500 XP`

주간 목표 달성 보너스는 동일한 주에 중복 계산하지 않는다. 기존 운동 기록을 주 단위로 묶고 해당 주의 운동 횟수가 사용자 목표 이상이면 150 XP를 한 번만 더한다.

## 레벨 표시 방식

사용자 프로필의 기존 `level` 값은 그대로 유지한다. 팝업에서는 계산된 총 XP를 현재 레벨 구간에 맞춰 다음처럼 표시한다.

- 현재 구간 XP: 현재 레벨 시작점 이후 쌓인 XP
- 필요 XP: `현재 레벨 × 500`
- 진행률: `현재 구간 XP / 필요 XP`
- 남은 XP: `필요 XP - 현재 구간 XP`

계산된 XP가 현재 레벨 필요치를 넘더라도 이번 기능에서는 저장된 레벨 값을 자동 변경하지 않는다. 자동 레벨업은 별도 기능으로 분리한다.

## UI 동작

- 홈의 기존 `Lv.N` 배지를 버튼으로 변경한다.
- 탭하면 배지 바로 아래에 팝업을 연다.
- 팝업 내용:
  - `Lv.N`
  - `현재 경험치`
  - `현재 XP / 필요 XP`
  - 진행 바와 백분율
  - `다음 레벨까지 N XP`
- 레벨 배지를 다시 누르면 닫힌다.
- 팝업 바깥을 누르거나 Escape 키를 누르면 닫힌다.
- 다른 홈 버튼의 터치 영역을 가리지 않도록 팝업 크기와 z-index를 제한한다.

## 파일 구조

### `src/game/experience.ts`

순수 계산 전용 파일이다.

- 운동 기록 XP 계산
- 개봉 카드팩 XP 계산
- 개인 기록 보너스 계산
- 주간 목표 달성 주 계산
- 현재 레벨 진행 정보 계산

### `src/screens/HomeScreen.tsx`

- 레벨 배지를 버튼으로 변경
- 팝업 열림 상태 관리
- 바깥 클릭과 Escape 처리
- 계산된 XP 정보 표시

### `src/screens/HomeScreen.css`

- 레벨 버튼 상태
- 경험치 팝업
- 진행 바
- 작은 모바일 화면 대응

## 접근성

- 레벨 버튼에 `aria-expanded`와 `aria-controls`를 제공한다.
- 팝업은 `role="dialog"`와 설명 가능한 제목을 갖는다.
- 진행 바는 `role="progressbar"`와 현재값을 제공한다.
- 키보드 Escape로 닫을 수 있다.

## 데이터 및 호환성

- `AppState`, `UserProfile`, 저장소 스키마를 변경하지 않는다.
- 기존 사용자 데이터에도 즉시 적용된다.
- 경험치 계산 결과는 새로고침 후에도 기존 기록을 기반으로 동일하게 재계산된다.
- 카드 확률, 보상 지급, 운동 기록 로직은 변경하지 않는다.

## 검증 기준

1. 레벨 배지를 누르면 팝업이 열린다.
2. 다시 누르거나 바깥을 누르면 닫힌다.
3. 운동 기록 1회당 100 XP가 반영된다.
4. 개봉 완료 카드팩 1개당 30 XP가 반영된다.
5. 개인 기록 운동은 추가 50 XP가 반영된다.
6. 주간 목표 달성 보너스는 같은 주에 한 번만 반영된다.
7. 현재 XP, 필요 XP, 남은 XP, 진행률이 서로 일치한다.
8. 팝업이 홈의 기록 버튼이나 카드팩 버튼 터치를 막지 않는다.
9. 저장 구조와 기존 기능이 변경되지 않는다.
