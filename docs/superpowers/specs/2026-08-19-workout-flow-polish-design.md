# Workout Flow Polish Design

## Goal
홈에서 시작한 운동 세션을 기록 화면까지 끊김 없이 이어가고, 상단 HUD 상세창과 홈 중앙 레이아웃을 정리한 뒤 운동 완료 보상을 명확하게 피드백한다.

## Approved flow
1. 홈에서 `오늘 운동 시작`을 누르면 공용 운동 타이머를 시작하고 기록 화면으로 이동한다.
2. 운동 중 기록 화면에서는 동일한 타이머가 계속 진행된다.
3. 홈에서 `운동 종료하기`를 누르면 타이머를 종료한 뒤 기록 화면으로 이동하고, 기록 화면은 방금 끝난 운동 시간을 `오늘 운동 HH:MM 완료` 상태로 표시한다.
4. 종료된 세션 시간은 기록 완료 시 운동 로그의 optional `durationSeconds`로 저장한다. 기존 저장 데이터는 그대로 호환한다.
5. 상단 Lv 상세창과 주간 목표 상세창은 같은 크기, 여백, 그림자, 모서리, 열림 애니메이션을 공유한다.
6. 홈 중앙은 `세트 진행도 → 오늘 운동 시작/종료 → 캐릭터` 순서의 시각적 흐름을 유지하며, 제거된 주간 큰 패널의 빈 공간을 남기지 않는다.
7. 기록 완료 후 즉시 홈으로 이동하지 않고 완료 피드백을 보여준다. 피드백에는 운동시간, 이번 주 진행도, 획득 XP, 카드팩 1개 획득을 표시하고 `홈으로` 버튼으로 종료한다.

## Constraints
- 기존 운동 기록/카드 보상/주간 목표 데이터 의미를 변경하지 않는다.
- 타이머 로컬 저장과 원격 그룹 세션 동기화는 기존 local-first 동작을 유지한다.
- 최근 종료 세션은 같은 로컬 날짜에서만 복원하며, 새 세션 시작 또는 기록 완료 시 폐기한다.
- XP 표시는 현재 경험치 규칙(운동 +100, 개인기록 +50, 주간 목표 달성 +150)을 그대로 계산한다.
- 카드 자체를 즉시 지급한 것으로 표현하지 않고 `카드팩 +1`로 표현한다.
