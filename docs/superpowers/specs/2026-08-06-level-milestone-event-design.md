# 10레벨 마일스톤 이벤트 설계

## 목표

사용자가 10, 20, 30레벨처럼 10레벨 단위에 최초 도달했을 때 일반 레벨업과 확실히 구분되는 축하 이벤트를 제공한다. 이벤트는 특별 카드팩, 기념 배지, 캐릭터 장식 해금을 한 번에 전달해 장기 성장 동기를 만든다.

이번 범위에서는 기존 운동 기록, 경험치 계산, 카드 획득 확률, 카드 도감 구조를 변경하지 않는다.

## 핵심 규칙

- 이벤트 대상 레벨은 10 이상의 10배수다.
- 각 마일스톤 이벤트는 계정 데이터 기준으로 한 번만 실행한다.
- 한 번에 여러 마일스톤을 넘어선 기존 저장 데이터는 가장 낮은 미수령 마일스톤부터 순서대로 처리한다.
- 이벤트를 닫거나 앱을 다시 실행해도 이미 지급한 보상이 중복 지급되지 않는다.
- 마일스톤 판정에는 저장된 `user.level`이 아니라 누적 경험치에서 계산한 실제 레벨을 사용한다.
- 마일스톤 보상 지급과 수령 기록은 하나의 reducer action에서 원자적으로 처리한다.

## 사용자 흐름

1. 운동 기록 또는 카드팩 개봉으로 경험치가 증가한다.
2. 홈 화면 진입 시 현재 실제 레벨에서 아직 수령하지 않은 10레벨 마일스톤을 찾는다.
3. 대상이 있으면 전체 화면 축하 모달을 연다.
4. 모달은 다음 내용을 순서대로 보여 준다.
   - `Lv.10 달성!`과 같은 레벨 달성 제목
   - 현재 선택 캐릭터의 축하 대사
   - CSS로 표현한 특별 선물상자
   - 특별 카드팩, 기념 배지, 장식 해금 안내
5. 사용자가 `보상 받기`를 누르면 보상을 한 번에 지급한다.
6. 지급 완료 화면에서 특별 카드팩을 바로 열거나 홈으로 돌아갈 수 있다.
7. 다음 미수령 마일스톤이 있으면 현재 이벤트를 닫은 뒤 이어서 표시한다.

## 보상 구성

### 특별 카드팩

- 마일스톤마다 `level-milestone` 출처의 카드팩 1개를 지급한다.
- 별도 복잡한 뽑기 시스템을 만들지 않고 기존 팩 개봉 화면과 카드 추첨 로직을 재사용한다.
- 팩 정의는 `pack-level-milestone` 하나를 공통 사용한다.
- 희귀도 분포는 레어 이상만 등장하도록 별도 마일스톤 확률표를 사용한다.
  - 레어 75%
  - 슈퍼 레어 20%
  - 레전드 5%
- 기존 전설 천장 카운터에는 영향을 주지 않는다.
- 실제 신규 이미지가 준비되기 전에는 CSS 선물상자와 기존 팩 표시 컴포넌트를 사용한다.

### 기념 배지

레벨별 표시 이름은 설정 테이블에서 관리한다.

- Lv.10 `Explorer`
- Lv.20 `Challenger`
- Lv.30 `Elite`
- Lv.40 `Master`
- Lv.50 `Legend`
- Lv.60 이상은 `Lv.{level} Milestone` 형식으로 자동 생성한다.

획득한 배지 중 가장 높은 레벨의 배지를 홈 화면 레벨 표시 옆에 노출한다. 별도 선택 UI는 이번 범위에서 만들지 않는다.

### 캐릭터 장식

이번 범위에서는 해금 상태만 저장한다.

- Lv.10 `sports-headband`
- Lv.20 `medal`
- Lv.30 `cape`
- Lv.40 `golden-aura`
- Lv.50 `crown`
- Lv.60 이상 `milestone-{level}`

장식 이미지와 실제 캐릭터 합성은 추후 에셋이 준비된 뒤 별도 작업으로 진행한다. 현재 화면에는 `장식 해금` 문구만 보여 준다.

## 데이터 구조

`AppState`에 아래 필드를 추가한다.

```ts
claimedLevelMilestones: number[];
earnedBadges: string[];
unlockedCosmetics: string[];
```

`GrantedPack.source`에는 다음 값을 추가한다.

```ts
'level-milestone'
```

마일스톤 팩에는 지급 근거를 보존한다.

```ts
sourceMilestoneLevel?: number;
```

기존 저장 데이터 마이그레이션 시 세 배열이 없으면 빈 배열로 초기화한다. 클라우드 저장 복원에도 같은 정규화 로직을 적용한다.

## 모듈 구성

### `src/game/levelMilestones.ts`

- 마일스톤 대상 판정
- 가장 낮은 미수령 마일스톤 선택
- 레벨별 배지·장식 정의 반환
- 축하 문구 반환

순수 함수만 포함해 단위 테스트가 가능하도록 한다.

### `src/store/GameContext.tsx`

- `CLAIM_LEVEL_MILESTONE` action 추가
- 수령 레벨 기록, 특별 팩 지급, 배지 및 장식 해금을 한 번에 처리
- 이미 수령한 레벨에는 아무 변화도 만들지 않음

### `src/screens/LevelMilestoneModal.tsx`

- 전체 화면 축하 모달
- 캐릭터 축하 대사
- 특별 선물상자 연출
- 보상 목록과 보상 받기 버튼
- 지급 완료 후 팩 열기와 홈 복귀 동작

### `src/screens/HomeScreen.tsx`

- 실제 경험치 레벨을 기준으로 미수령 마일스톤 확인
- 대상이 있을 때 모달 표시
- 가장 높은 획득 배지를 레벨 표시 옆에 노출

## 화면과 연출

- 모바일 세로 화면을 기준으로 구성한다.
- 전체 배경을 어둡게 하고 중앙에 금색·보라색 계열 축하 패널을 둔다.
- 선물상자는 신규 이미지 없이 CSS 도형과 반짝임으로 표현한다.
- 지속적인 무거운 애니메이션은 사용하지 않는다.
- 모달 진입, 상자 등장, 보상 목록 등장만 짧게 순차 실행한다.
- `prefers-reduced-motion`에서는 모든 이동 애니메이션을 제거한다.
- 모달은 `role="dialog"`, `aria-modal="true"`를 사용하고 열린 동안 배경 스크롤을 잠근다.

## 중복 지급 방지

`CLAIM_LEVEL_MILESTONE` reducer는 다음 순서로 처리한다.

1. 요청 레벨이 10 이상의 10배수인지 검증한다.
2. 현재 실제 레벨 이하인지 검증한다.
3. `claimedLevelMilestones`에 이미 존재하면 기존 state를 그대로 반환한다.
4. 마일스톤 팩 ID를 생성한다.
5. 마일스톤 수령 기록, 팩, 배지, 장식을 한 번의 새 state로 반환한다.

버튼 연속 클릭과 React 재렌더링이 발생해도 reducer 검증으로 중복 지급을 막는다.

## 기존 데이터 처리

기존 사용자가 이미 Lv.10 이상이지만 마일스톤 데이터가 없다면 다음 홈 진입 시 Lv.10 이벤트부터 보여 준다. 한 화면에서 여러 보상을 한꺼번에 지급하지 않고 각 마일스톤 이벤트를 순서대로 경험하게 한다.

이 방식은 과거 달성 보상을 놓치지 않으면서도 중복 지급과 복잡한 일괄 보상 UI를 피한다.

## 오류 및 예외 처리

- 카드팩 정의를 찾지 못하면 마일스톤을 수령 처리하지 않고 오류 안내를 표시한다.
- 로컬 저장 실패 시 기존 앱 정책대로 메모리 상태는 유지하고 경고만 기록한다.
- 이벤트 도중 새로고침하면 미수령 상태라면 다시 모달을 표시하고, 이미 보상 받기를 눌렀다면 다시 지급하지 않는다.
- 최고 레벨 제한은 두지 않으며 10배수마다 자동 확장한다.

## 테스트

### 순수 함수

- 9레벨에는 이벤트가 없다.
- 10레벨에는 Lv.10 이벤트가 있다.
- Lv.30이며 10만 수령했으면 20을 먼저 반환한다.
- 모든 대상 레벨을 수령했으면 이벤트가 없다.
- 레벨별 배지와 장식 ID가 안정적으로 반환된다.

### reducer

- 최초 수령 시 팩·배지·장식·수령 기록이 모두 추가된다.
- 동일 마일스톤 재요청은 state를 변경하지 않는다.
- 잘못된 레벨 요청은 state를 변경하지 않는다.
- 기존 보유 팩과 카드 데이터는 보존된다.

### 화면

- 미수령 이벤트가 있을 때 모달이 열린다.
- 보상 받기 버튼이 action을 한 번만 호출한다.
- 지급 완료 후 해당 팩 개봉 화면으로 이동할 수 있다.
- 획득 배지가 홈 레벨 옆에 표시된다.
- ESC와 닫기 동작은 지급 전에는 이벤트를 보류하고, 다음 홈 진입 시 다시 표시한다.

## 제외 범위

- 캐릭터 장식의 실제 이미지 합성
- 배지 선택·교체 화면
- 마일스톤 전용 신규 카드
- 서버 검증형 보상 지급
- 마일스톤 다시 보기 갤러리
- 소셜 공유
- 유료 보상 또는 상점 연동

## 완료 기준

- 실제 레벨 10배수 최초 달성 시 이벤트가 정확히 한 번 표시된다.
- 특별 카드팩, 배지, 장식 해금 데이터가 중복 없이 저장된다.
- 기존 저장 데이터 사용자도 달성한 마일스톤을 순서대로 받을 수 있다.
- 기존 운동 기록, 일반 카드팩, 카드 도감, 클라우드 저장 기능이 그대로 동작한다.
- 테스트와 빌드 결과를 실제로 확인한 경우에만 성공으로 보고한다.
