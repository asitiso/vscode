# 운동 기록 화면 레이아웃 개선 설계

## 목표

현재 `RecordScreen`의 모든 기능, 상태, 저장 흐름, 데이터 구조를 유지한 채 시각적 위계와 배치만 개선한다. 사용자가 운동 기록 화면을 열었을 때 무엇을 먼저 보고, 어디를 눌러야 하는지 즉시 이해할 수 있어야 한다.

## 범위

수정 대상은 `src/screens/RecordScreen.tsx`와 `src/screens/RecordScreen.css`를 중심으로 한다. 공통 레이아웃이나 하단 내비게이션과의 간격 조정이 필요한 경우에만 최소 범위로 관련 스타일을 수정한다.

다음 항목은 변경하지 않는다.

- 운동 선택 로직
- 최근 운동 데이터
- 운동 추가 및 삭제 동작
- 세트, 횟수, 시간 입력 로직
- 오늘의 느낌 선택값
- 메모 입력과 저장 방식
- 기록 완료 버튼의 처리 로직
- 상태 관리 및 저장소 구조
- 카드팩 지급 및 다음 화면 이동 흐름

## 권장 레이아웃

### 1. 상단 헤더

화면 맨 위에 `오늘의 운동 기록` 제목과 짧은 안내 문구를 배치한다. 현재 배경 일러스트는 제거하지 않고 상단 분위기 요소로 남기되, 텍스트와 입력 영역 뒤에서는 대비를 방해하지 않도록 밝기와 불투명도를 낮춘다.

### 2. 최근 운동 영역

최근 운동은 별도 밝은 카드에 배치한다. 자주 쓰는 항목을 바로 선택할 수 있도록 유지하며, 다른 입력 영역과 섞이지 않게 구분한다.

### 3. 운동 선택 영역

운동 카테고리와 운동 목록을 하나의 큰 카드 안에서 단계적으로 보여준다. 선택된 항목은 보라색 계열의 채움과 흰색 글자로 표시하고, 선택되지 않은 항목은 흰색 배경과 명확한 테두리를 사용한다.

### 4. 세트 기록 영역

현재 입력 구조와 동작을 그대로 유지하되 각 운동별 기록 블록을 분리된 카드 또는 행으로 정리한다. 숫자 입력과 증감 버튼은 터치 영역을 충분히 확보한다.

### 5. 오늘의 느낌 영역

느낌 선택지는 독립 카드로 분리한다. 선택 상태가 한눈에 보이도록 선택 항목은 강조색, 미선택 항목은 밝은 배경을 적용한다.

### 6. 메모 영역

메모는 선택 항목임을 분명히 표시하고 시각적 우선순위를 낮춘다. 입력창은 밝은 단색 배경을 사용해 배경 이미지와 겹쳐도 읽기 쉽도록 한다.

### 7. 완료 버튼과 하단 메뉴

`기록 완료` 버튼은 모든 입력 영역 아래에 넓게 배치한다. 하단 고정 메뉴와 겹치지 않도록 모바일 안전 여백과 충분한 하단 패딩을 둔다.

## 시각 스타일

- 배경: 기존 일러스트 유지, 본문 영역은 밝은 크림색 또는 흰색 카드
- 텍스트: 제목과 주요 레이블은 짙은 남색 또는 짙은 회색
- 강조색: 보라색 계열을 선택 상태와 주요 버튼에 사용
- 테두리: 흐린 반투명 테두리 대신 명확한 1~2px 경계
- 모서리: 기존 앱 분위기에 맞는 둥근 모서리
- 그림자: 카드 구분에 필요한 약한 그림자만 사용
- 투명 효과: 본문 입력 영역에서는 최소화

## 반응형 기준

다음 모바일 폭에서 내용 잘림, 겹침, 가로 스크롤이 없어야 한다.

- 375px
- 390px
- 430px

하단 고정 내비게이션이 있는 환경에서도 완료 버튼과 마지막 입력 항목이 가려지지 않아야 한다.

## 구현 원칙

- 이벤트 핸들러와 상태 변수는 유지한다.
- JSX 순서는 시각적 위계를 위해 재배치할 수 있지만 데이터 흐름은 변경하지 않는다.
- 새로운 기능, 탭, 진행도, 레벨 요소를 추가하지 않는다.
- 기존 컴포넌트가 재사용 가능하면 유지한다.
- 불필요한 전역 스타일 변경은 하지 않는다.

## 검증

- 기존 운동 선택과 입력이 동일하게 작동하는지 확인
- 기록 완료 후 기존 카드팩 흐름으로 이동하는지 확인
- 선택 상태가 시각적으로 명확한지 확인
- 375px, 390px, 430px에서 레이아웃 확인
- `npm run build` 성공 여부 확인
- 가능하면 기존 린트 또는 테스트 명령도 실행

## 완료 기준

사용자가 화면을 열었을 때 제목, 최근 운동, 운동 선택, 세트 기록, 느낌, 메모, 완료 버튼의 순서를 즉시 이해할 수 있고, 기존 기능은 모두 이전과 동일하게 작동해야 한다.
