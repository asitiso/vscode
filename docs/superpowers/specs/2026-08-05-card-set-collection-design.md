# 카드 세트 컬렉션과 오늘의 세트 보너스 설계

## 목표

기존 운동 기록, 카드팩 개봉, 카드 도감, 홈 캐릭터 시스템을 유지하면서 사용자가 다음 카드를 기대하고 세트 완성을 목표로 반복 플레이하도록 만든다.

핵심 루프는 다음과 같다.

`운동 기록 → 상자 획득 → 카드 개봉 → 세트 진행 → 세트 완성 보상 → 다음 세트 도전`

이번 업데이트는 새로운 재화와 새로운 탭을 만들지 않고 기존 홈, 도감, 보상상자 안에서 해결한다.

## 카드 세트 구성

현재 카드 24종을 6세트로 나눈다. 각 세트는 4장으로 구성한다.

### 유산소 스타터

- 러닝머신
- 실내 자전거
- 스텝밀
- 로잉머신

### 하체 머신

- 레그프레스
- 레그익스텐션
- 레그컬
- 스쿼트랙

### 가슴 강화

- 체스트프레스
- 펙덱플라이
- 인클라인 벤치프레스
- 딥스 스탠드

### 등 당기기

- 랫풀다운
- 시티드로우
- 풀업 바
- 케이블머신

### 프리웨이트

- 덤벨
- 바벨
- 케틀벨
- 스미스머신

### 전신 밸런스

- 숄더프레스
- 복근운동 기구
- 스트레칭 매트
- 폼롤러

실제 구현에서는 카드 이름 문자열이 아니라 카드 ID로 세트를 정의한다.

## 세트 진행과 완성 기준

- 세트에 속한 카드를 한 번이라도 획득하면 해당 카드가 수집된 것으로 처리한다.
- 카드의 중복 획득 수, 별 단계, 희귀도는 세트 완성 조건에 영향을 주지 않는다.
- 4장 중 4장을 모두 획득하면 세트가 완성된다.
- 사용자 직접 입력 운동과 그 기록은 카드 세트 조건에 포함하지 않는다.
- 카드 삭제 기능이 없으므로 한 번 완성된 세트는 다시 미완성 상태가 되지 않는다.

세트 진행 정보는 보유 카드 상태에서 계산한다. 별도의 진행 수치를 중복 저장하지 않는다.

## 세트 완성 보상

세트 하나를 처음 완성했을 때 다음 보상을 한 번만 지급한다.

- 세트 특별 보상상자 1개
- 세트 완성 배지
- 세트 전용 칭호 수집
- 홈 캐릭터 축하 대사

칭호는 이번 버전에서 장착 기능을 만들지 않는다. 완성 정보와 함께 수집된 상태만 보여준다.

### 칭호 문구

- 유산소 스타터: `심장이 뛴다`
- 하체 머신: `튼튼한 하체`
- 가슴 강화: `강철 가슴`
- 등 당기기: `등이 말한다`
- 프리웨이트: `철을 다루는 자`
- 전신 밸런스: `균형의 달인`

## 특별 보상상자 규칙

기존 `GrantedPack`과 카드 개봉 화면을 재사용하되, 세트 완성 상자를 구분할 수 있는 팩 정의 또는 보상 출처 정보를 추가한다.

추천 확률은 다음과 같다.

- 레어: 70%
- 슈퍼레어: 25%
- 레전더리: 5%
- 일반: 0%

추가 규칙:

- 완성한 세트에 속한 카드가 같은 등급의 다른 카드보다 더 높은 가중치를 가진다.
- 중복 카드도 등장할 수 있다.
- 레전더리 천장 카운터에는 기존 상자와 동일하게 반영한다.
- 기존 일반 상자의 확률, 천장, 별 단계, 중복 성장 규칙은 변경하지 않는다.
- 새로운 카드 조각이나 재화를 지급하지 않는다.

## 오늘의 세트 보너스

매일 6개 세트 중 하나를 오늘의 집중 세트로 선정한다.

### 선정 방식

- 로컬 날짜 `YYYY-MM-DD`와 고정된 세트 목록을 입력으로 사용하는 결정적 계산을 사용한다.
- 같은 날짜에는 새로고침하거나 앱을 다시 실행해도 같은 세트가 나온다.
- 별도의 저장 상태를 만들지 않는다.
- 날짜가 바뀌면 자동으로 다음 세트가 선정된다.
- 6일 주기 순환 대신 날짜 해시를 사용하되, 구현은 테스트 가능한 순수 함수로 만든다.

### 보너스 효과

오늘의 세트에 속한 카드의 기존 관련 카드 가중치에 1.5배 효과를 적용한다.

현재 카드 선택 로직이 정수 배열 복제 방식이라면 가중치 단위를 정수로 환산한다. 예를 들어 일반 관련 카드 3, 오늘의 세트 관련 카드 5로 처리할 수 있다. 정확한 사용자 화면에는 수치를 노출하지 않고 `등장 확률 UP`만 표시한다.

오늘의 보너스는 세트 특별상자에도 적용할 수 있지만, 특별상자 자체의 완성 세트 가중치가 우선한다. 두 가중치를 중복 곱하지 않고 더 높은 하나만 적용한다.

## 홈 화면

새로운 큰 섹션을 만들지 않고 기존 오늘 활동 또는 보상 영역 근처에 작은 진행 카드 하나를 추가한다.

### 기본 상태

표시할 세트는 다음 우선순위로 결정한다.

1. 미완성 세트 중 완성까지 남은 카드가 가장 적은 세트
2. 남은 수가 같으면 오늘의 세트
3. 모든 세트 진행도가 0이면 오늘의 세트

표시 예:

> 다음 완성까지 1장  
> 등 당기기 세트 3 / 4  
> 풀업 바 카드만 남았어요

카드를 누르면 도감 화면으로 이동하고 해당 세트가 보이도록 한다.

### 보상 미수령 상태

세트가 완성됐지만 보상상자를 아직 받지 않았다면 일반 진행 카드보다 우선해 표시한다.

> 세트 완성!  
> 등 당기기 세트를 모두 모았어요  
> 특별상자 받기

상자를 실제로 지급하는 시점은 세트 완성 감지 직후로 통일한다. 홈의 `특별상자 받기`는 미지급 생성이 아니라 이미 지급된 미개봉 상자로 이동하는 버튼으로 사용한다. 이 방식으로 중복 지급을 방지한다.

### 오늘의 세트 표시

진행 카드 안 또는 바로 아래에 다음 정보를 작게 표시한다.

> 오늘의 집중 세트: 하체 머신  
> 관련 카드 등장 확률 UP

홈 정보량이 과해지지 않도록 오늘의 세트 전용 대형 카드는 만들지 않는다.

## 도감 화면

새 탭을 추가하지 않는다.

도감 상단에 세트 필터를 제공한다.

- 전체
- 유산소
- 하체
- 가슴
- 등
- 프리웨이트
- 전신 밸런스

각 세트 화면 또는 영역에는 다음을 표시한다.

- 세트 이름
- `획득 카드 수 / 4`
- 진행률 막대
- 카드 4장
- 미획득 카드 실루엣
- 완성 세트의 `완성` 배지
- 수집한 칭호

필터는 기존 도감 카드 그리드를 재사용한다. 별도의 라우트나 탭을 만들지 않는다.

## 세트 완성 감지와 연출

세트 완성 여부는 카드팩 개봉 결과가 상태에 반영된 직후 계산한다.

처리 순서:

1. 카드 한 장을 획득한다.
2. 획득 전 미완성이고 획득 후 완성된 세트를 찾는다.
3. 해당 세트가 이전에 보상 처리된 적이 없는지 확인한다.
4. 세트 특별상자 1개를 지급한다.
5. 완성 처리된 세트 ID를 저장한다.
6. 카드 결과 화면에서 세트 완성 연출을 표시한다.

연출 순서:

1. 기존 카드 개봉 결과 표시
2. `세트 완성!` 메시지
3. 세트 카드 4장 또는 카드 이름 요약
4. 특별상자 지급 안내
5. 확인 또는 건너뛰기

연출 전체는 짧게 유지하고 사용자가 즉시 건너뛸 수 있어야 한다.

## 캐릭터 대사

세트 완성 직후 홈 캐릭터의 문맥 대사 우선순위에 `최근 세트 완성`을 추가한다.

예:

- `우와! 등 당기기 세트를 전부 모았어!`
- `특별상자가 도착했어. 열어보자!`
- `다음 세트도 얼마 남지 않았어!`

세트 완성 대사는 영구 해금된 대사 목록으로 복잡하게 관리하지 않는다. 최근 완성 이벤트 또는 완성 세트 수에 따라 상황 대사로 제공한다.

## 저장 상태

최소한 다음 상태를 추가한다.

- `completedSetIds: string[]`
- `rewardedSetIds: string[]`

단, 카드 보유 상태로 완성 여부를 계산할 수 있으므로 `completedSetIds`는 기록과 축하 상태 유지에만 사용한다. 중복 보상 방지의 기준은 `rewardedSetIds`다.

세트 특별상자는 기존 `grantedPacks` 배열에 저장한다. 필요하면 다음 선택 필드를 추가한다.

- `source?: 'workout' | 'set-completion'`
- `sourceSetId?: string`

기존 저장 데이터에는 새 필드가 없으므로 다음 기본값으로 마이그레이션한다.

- `completedSetIds: []`
- `rewardedSetIds: []`
- 기존 팩의 `source`는 `workout`으로 간주

## 중복 지급 방지

- `rewardedSetIds`에 포함된 세트에는 다시 상자를 지급하지 않는다.
- 같은 카드팩 개봉 액션이 중복 호출돼도 이미 열린 팩은 기존 로직대로 무시한다.
- 여러 세트의 마지막 카드가 동일하지 않도록 세트를 구성하므로 한 카드 획득으로 한 세트만 완성되는 구조를 유지한다.
- 저장 직후 새로고침해도 동일 세트 보상이 다시 생성되지 않아야 한다.

## 오류와 안전 처리

- 세트 정의에 존재하지 않는 카드 ID가 있으면 해당 카드는 진행 계산에서 무시하고 개발 경고를 남긴다.
- 카드 세트가 비어 있거나 카드 수가 4장이 아니면 개발 테스트에서 실패시킨다.
- 특별상자 후보 등급에 카드가 없으면 기존 전체 카드 풀로 안전하게 폴백한다.
- 오늘의 날짜 계산은 사용자의 로컬 날짜를 사용한다.
- 사용자 직접 입력 운동은 관련 카드가 없으므로 오늘의 세트 보너스 대상에 영향을 주지 않는다.

## 테스트 범위

### 세트 정의

- 6세트가 존재한다.
- 각 세트는 카드 4장이다.
- 카드 ID가 중복되지 않는다.
- 모든 카드 ID가 실제 카드 정의에 존재한다.

### 진행 계산

- 미획득, 일부 획득, 전체 획득 진행률
- 중복 카드가 진행률을 추가로 올리지 않음
- 가장 가까운 미완성 세트 선택
- 동률일 때 오늘의 세트 우선

### 오늘의 세트

- 같은 날짜에 같은 결과
- 다른 날짜에 유효한 세트 결과
- 로컬 날짜 기준 전환
- 카드 가중치가 오늘의 세트에만 적용

### 완성 보상

- 마지막 카드 획득 시 특별상자 1개 지급
- 이미 보상된 세트는 재지급하지 않음
- 새로고침 후 중복 지급하지 않음
- 특별상자에서 일반 카드가 나오지 않음
- 레어, 슈퍼레어, 레전더리 확률 경계 테스트
- 천장 카운터 반영

### UI

- 홈 진행 카드 표시
- 보상 미개봉 상태 우선 표시
- 오늘의 집중 세트 표시
- 도감 세트 필터
- 미획득 실루엣
- 완성 배지와 칭호
- 세트 완성 연출 건너뛰기

### 회귀

- 기본 운동 기록과 사용자 직접 입력 운동 기록
- 일반 보상상자 지급 및 개봉
- 카드 별 성장과 중복 처리
- 레벨 경험치 팝업
- 홈 캐릭터 클릭 상호작용
- 기존 저장 데이터 마이그레이션

## 범위 제외

이번 작업에서는 다음을 구현하지 않는다.

- 카드 조각
- 카드 확정 제작
- 새로운 화폐
- 칭호 장착과 프로필 편집
- 세트별 별 등급 완성
- 친구 비교와 공유
- 선택형 일일 미션 3개
- 새 도감 탭 또는 새 라우트
- 서버 동기화

## 완료 기준

- 24종 카드가 6개 세트로 표시된다.
- 홈에서 가장 완성에 가까운 세트를 확인할 수 있다.
- 매일 오늘의 집중 세트가 표시되고 관련 카드 가중치가 적용된다.
- 마지막 카드를 획득하면 특별상자가 정확히 한 번 지급된다.
- 도감에서 세트 진행, 실루엣, 완성 배지, 칭호를 확인할 수 있다.
- 기존 기록, 보상, 카드 성장, 사용자 직접 입력 운동 기능이 깨지지 않는다.
