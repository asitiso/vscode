# 홈 캐릭터 상호작용 설계

## 목표

홈 화면의 캐릭터를 누르면 짧은 반응 애니메이션과 현재 게임 상황에 맞는 대화 말풍선을 보여준다. 대화는 상황별 문장 그룹 안에서 무작위로 선택해 반복감을 줄이고, 캐릭터가 홈 화면의 안내자이자 응원 역할을 하도록 만든다.

## 사용자 경험

1. 사용자가 홈 캐릭터를 누른다.
2. 캐릭터가 클릭 반응 애니메이션 중 하나를 재생한다.
3. 현재 상태에 맞는 대화 그룹을 선택한다.
4. 선택된 그룹 안에서 직전 문장과 다른 문장을 무작위로 표시한다.
5. 말풍선은 약 3초 후 자동으로 닫힌다.
6. 캐릭터를 다시 누르면 새 움직임과 새 문장을 즉시 표시한다.
7. 말풍선을 누르면 즉시 닫힌다.

## 상황 판정 우선순위

여러 조건이 동시에 참이면 아래 순서로 하나의 대화 그룹만 선택한다.

1. 미개봉 보상이 있음
2. 주간 목표까지 정확히 1회 남음
3. 주간 목표를 달성함
4. 오늘 운동을 완료함
5. 연속 기록이 1주 이상 유지 중
6. 오늘 운동 전
7. 기본 대화

미개봉 보상은 사용자가 바로 다음 행동을 할 수 있는 가장 강한 신호이므로 최우선으로 둔다. 주간 목표 임박도 행동 유도성이 높아 완료 상태보다 앞에 둔다.

## 문장 선택 규칙

- 선택된 상황 그룹에서 한 문장을 무작위로 고른다.
- 직전에 표시된 문장은 후보에서 제외한다.
- 후보가 한 개뿐이거나 제외 후 후보가 없으면 전체 그룹에서 다시 선택한다.
- 직전 문장은 컴포넌트 메모리에서만 관리하며 저장소에는 기록하지 않는다.
- 앱 새로고침 후 같은 문장이 다시 나오는 것은 허용한다.

## 캐릭터 움직임

클릭할 때 다음 반응 중 하나를 무작위로 선택한다.

- `bounce`: 위로 통통 뛰고 착지
- `wiggle`: 좌우로 빠르게 흔들기
- `wave`: 살짝 기울어졌다 돌아오며 인사하는 느낌
- `jump`: 크게 한 번 점프
- `double-pop`: 짧게 두 번 튀기

### 애니메이션 규칙

- 기존 `character-bob` 기본 애니메이션은 평상시에 유지한다.
- 클릭 반응 중에는 기본 애니메이션을 잠시 중단한다.
- 클릭 반응은 500~800ms 안에 끝난다.
- 애니메이션 종료 후 기본 둥실 애니메이션으로 돌아간다.
- 빠르게 다시 클릭하면 기존 반응을 취소하고 새 반응을 처음부터 재생한다.
- `prefers-reduced-motion: reduce` 환경에서는 이동을 최소화하고 짧은 크기 변화만 사용한다.

## 말풍선 UI

- 캐릭터 바로 위에 흰색 말풍선을 표시한다.
- 짙은 남색 텍스트와 보라색 테두리를 사용해 보상·기록 화면과 톤을 맞춘다.
- 아래쪽 중앙에 캐릭터를 향하는 꼬리를 둔다.
- 최대 너비는 홈 화면 폭의 약 70%, 최대 두 줄을 기본으로 한다.
- 긴 문장은 자연스럽게 줄바꿈하며 텍스트가 잘리지 않아야 한다.
- 말풍선은 캐릭터와 함께 홈의 중간 영역에만 머물러 상단 진행 패널과 하단 내비게이션을 가리지 않는다.
- 미개봉 카드팩이 오른쪽에 있을 때도 카드팩 터치 영역을 막지 않도록 말풍선의 `pointer-events`와 폭을 제한한다.
- 말풍선 자체는 버튼으로 제공해 누르면 닫을 수 있게 한다.

## 접근성

- 캐릭터 영역을 `button` 요소로 변경한다.
- `aria-label="캐릭터와 대화하기"`를 제공한다.
- 말풍선은 `role="status"`와 `aria-live="polite"`를 사용한다.
- 키보드 Enter와 Space로 캐릭터 반응을 실행할 수 있어야 한다.
- 말풍선 닫기 버튼에 표시 문장을 포함한 설명 가능한 `aria-label`을 제공한다.
- 포커스 표시를 제거하지 않는다.

## 컴포넌트 구조

### `src/game/characterDialogue.ts`

순수 데이터와 선택 로직을 담당한다.

- `CharacterDialogueContext` 타입
- `CharacterDialogueGroup` 타입
- 상황 우선순위 판정 함수
- 대화 문장 그룹 상수
- 직전 문장 제외 랜덤 선택 함수

예상 공개 인터페이스:

```ts
export type CharacterDialogueContext = {
  hasUnopenedPack: boolean;
  remainingWeeklySessions: number;
  weeklyGoalComplete: boolean;
  todayLogged: boolean;
  streak: number;
};

export function selectCharacterDialogue(
  context: CharacterDialogueContext,
  previousMessage?: string,
  random?: () => number,
): string;
```

테스트에서 결과를 고정할 수 있도록 선택 함수는 선택적 `random` 함수를 받는다.

### `src/screens/HomeCharacterInteraction.tsx`

표시 상태와 사용자 상호작용을 담당한다.

- 기존 캐릭터 이미지 렌더링
- 클릭 이벤트 처리
- 무작위 애니메이션 선택
- 현재 문장과 직전 문장 관리
- 3초 자동 닫힘 타이머
- 연속 클릭 시 타이머 초기화
- 언마운트 시 타이머 정리

예상 props:

```ts
interface HomeCharacterInteractionProps {
  assetName: string;
  dialogueContext: CharacterDialogueContext;
}
```

### `src/screens/HomeCharacterInteraction.css`

- 클릭 가능한 캐릭터 버튼
- 기본 둥실 애니메이션
- 다섯 가지 반응 애니메이션
- 말풍선과 꼬리
- 작은 모바일 화면 대응
- 모션 감소 설정 대응

### `src/screens/HomeScreen.tsx`

- 기존 캐릭터 `div`와 `PlaceholderArt` 직접 렌더링을 `HomeCharacterInteraction`으로 교체한다.
- `todayLogged`, `unopenedPacks`, `weeklyProgress`에서 대화 컨텍스트를 구성한다.
- 홈의 다른 동작과 레이아웃은 변경하지 않는다.

### `src/screens/HomeScreen.css`

- 기존 `.home-screen__character` 위치와 크기 규칙은 유지한다.
- 캐릭터 이미지에 직접 걸린 `character-bob` 애니메이션 규칙은 새 컴포넌트 CSS로 이동한다.
- 다른 홈 요소 스타일은 변경하지 않는다.

## 상태 및 데이터 흐름

`HomeScreen`이 기존 `useGame()` 결과에서 다음 값을 전달한다.

- `hasUnopenedPack`: `unopenedPacks.length > 0`
- `remainingWeeklySessions`: `weeklyProgress.remainingThisWeek`
- `weeklyGoalComplete`: `weeklyProgress.remainingThisWeek === 0`
- `todayLogged`: 기존 계산값
- `streak`: `weeklyProgress.streak`

`HomeCharacterInteraction`은 클릭 순간에 컨텍스트를 `selectCharacterDialogue`에 전달한다. 게임 상태가 바뀌면 다음 클릭부터 새 상황이 반영된다. 대화나 애니메이션 결과를 `AppState`에 저장하지 않는다.

## 타이머 및 오류 처리

- 대화 표시 타이머는 `window.setTimeout` 한 개만 유지한다.
- 새 클릭이 발생하면 기존 타이머를 먼저 해제한다.
- 컴포넌트가 언마운트될 때 타이머를 해제한다.
- 대화 그룹이 비어 있는 비정상 상황에서는 기본 문장 `오늘도 함께해 줘서 고마워!`를 반환한다.
- 이미지 로딩 실패 처리는 기존 `PlaceholderArt` 동작을 그대로 사용한다.

## 변경하지 않는 범위

- 캐릭터 이미지 자산
- 캐릭터 선택 기능과 저장 데이터
- 운동 기록 저장 로직
- 주간 진행 계산 로직
- 보상 지급과 카드팩 개봉 로직
- 홈 상단 레벨 경험치 팝업
- 홈의 기록 버튼과 카드팩 버튼 위치
- 앱 전역 저장소 스키마

## 테스트 계획

### 대화 로직 단위 테스트

- 미개봉 보상이 다른 모든 상황보다 우선되는지 확인
- 목표 1회 남음이 목표 달성·오늘 운동 완료보다 우선되는지 확인
- 오늘 운동 완료와 연속 기록 우선순위 확인
- 아무 조건이 없을 때 운동 전 또는 기본 그룹 선택 확인
- 직전 문장이 다음 후보에서 제외되는지 확인
- 고정 `random` 함수로 예상 문장이 선택되는지 확인
- 빈 후보에서 안전한 기본 문장을 반환하는지 확인

### 컴포넌트 동작 검증

- 캐릭터 클릭 시 말풍선이 나타나는지 확인
- 다시 클릭하면 타이머가 초기화되고 문장이 갱신되는지 확인
- 약 3초 후 자동으로 닫히는지 확인
- 말풍선 클릭 시 즉시 닫히는지 확인
- 컴포넌트 언마운트 후 타이머가 실행되지 않는지 확인
- 캐릭터 버튼의 접근성 속성이 존재하는지 확인

### 화면 검증

- 375×667, 390×844, 430×932에서 말풍선이 화면 밖으로 나가지 않는지 확인
- 말풍선이 기록 버튼과 카드팩 버튼을 가리지 않는지 확인
- 반응 애니메이션 후 기본 둥실 동작으로 복귀하는지 확인
- 모션 감소 환경에서 큰 이동 없이 반응하는지 확인

## 완료 기준

1. 홈 캐릭터가 마우스·터치·키보드로 클릭 가능하다.
2. 클릭할 때 다섯 가지 반응 중 하나가 실행된다.
3. 현재 상태에 맞는 대화 그룹에서 문장이 표시된다.
4. 같은 문장이 연속으로 표시되지 않는다.
5. 말풍선이 약 3초 후 자동으로 닫힌다.
6. 빠른 연속 클릭과 화면 이동 후에도 타이머 오류가 없다.
7. 말풍선이 다른 홈 버튼의 터치를 방해하지 않는다.
8. 기존 홈 기능과 저장 구조가 변경되지 않는다.
