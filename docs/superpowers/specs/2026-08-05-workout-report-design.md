# 운동 리포트 설계

## 목표

보상 화면 안에 `운동 리포트` 탭을 추가해 사용자가 저장된 전체 운동 기록을 주간·월간 단위로 계속 조회하고, 어떤 운동을 얼마나 했는지 과거부터 현재까지 쉽게 비교할 수 있도록 한다.

## 화면 위치와 탐색 구조

보상 화면의 상단 탭은 다음 순서로 구성한다.

`오늘 활동 | 운동 리포트 | 연속 보상`

운동 리포트 내부에는 `주간 | 월간` 전환을 둔다. 별도의 하단 탭이나 새 화면은 만들지 않는다.

주간과 월간 모두 이전 기간과 다음 기간으로 이동할 수 있다. 조회 가능 범위는 저장된 첫 운동 기록이 속한 기간부터 현재 기간까지다. 현재보다 미래 기간으로는 이동할 수 없다.

## 데이터 원칙

리포트 전용 통계 데이터를 별도로 저장하지 않는다. 기존 `AppState.workoutLogs`를 단일 원본으로 사용하고 화면 진입 시 선택 기간의 통계를 계산한다.

이 방식은 다음을 보장한다.

- 기존 사용자의 과거 운동 기록도 즉시 리포트에 반영된다.
- 이후 기록 수정 기능이 생기면 리포트가 자동으로 갱신된다.
- 중복 저장과 통계 데이터 마이그레이션을 피한다.
- 삭제된 사용자 운동도 `WorkoutSetEntry.exerciseName` 스냅샷을 이용해 과거 이름을 유지한다.

날짜 계산은 사용자의 로컬 날짜 `YYYY-MM-DD`를 기준으로 한다. UTC 문자열 절단으로 주·월 경계가 바뀌지 않도록 공통 로컬 날짜 유틸리티를 사용한다.

## 공통 집계 항목

주간·월간 리포트는 아래 항목을 동일하게 제공한다.

- 운동일 수: 운동 기록이 하나 이상 존재하는 서로 다른 날짜 수
- 운동 기록 횟수: 해당 기간의 `WorkoutLog` 개수
- 운동 종목 수: 해당 기간에 등장한 서로 다른 운동 ID 수
- 총 운동 시간: 모든 `durationMinutes` 합계
- 총 세트: 모든 `sets` 합계
- 총 반복: 각 항목의 `reps × max(sets, 1)` 합계
- 가장 많이 한 운동: 해당 운동이 등장한 서로 다른 날짜 수 기준 1위
- 카테고리 분포: 해당 카테고리가 등장한 운동 항목 수 기준

같은 운동을 하루에 여러 번 기록해도 가장 많이 한 운동의 날짜 수에는 하루 1회만 반영한다.

시간·세트·반복 값이 없는 기간에도 해당 통계를 숨기지 않고 각각 `0분`, `0세트`, `0회`로 표시한다.

기록이 전혀 없는 기간도 조회할 수 있다. 요약 수치는 모두 0으로 표시하고 `이 기간에는 운동 기록이 없어요` 안내 문구를 보여준다.

## 이전 기간 비교

주간은 바로 이전 주와, 월간은 바로 이전 달과 비교한다.

비교 항목은 다음과 같다.

- 운동일 수
- 운동 기록 횟수
- 운동 종목 수
- 총 운동 시간
- 총 세트
- 총 반복

표시는 `지난주보다 +1일`, `지난달보다 -8세트`처럼 간단한 증감 문구를 사용한다. 이전 기간 값이 0인 경우 퍼센트 대신 절대 증감만 표시한다.

## 주간 리포트

주간 범위는 월요일 00:00부터 일요일 23:59까지다.

상단에는 선택된 주의 날짜 범위와 이전 주·다음 주 버튼을 표시한다.

요약 영역 다음에는 월요일부터 일요일까지 7개의 날짜 행을 보여준다. 각 행에는 다음을 표시한다.

- 요일과 날짜
- 운동 기록 여부
- 운동 종목 수
- 총 시간 또는 총 세트
- 대표 카테고리 점

운동한 날짜를 누르면 날짜별 상세 기록 바텀시트를 연다. 기록이 없는 날짜는 선택하지 않거나 빈 상태 안내만 표시한다.

## 월간 리포트

상단에는 선택된 연·월과 이전 달·다음 달 버튼을 표시한다.

월간 달력은 월요일 시작 7열 구조로 구성한다. 각 날짜 셀에는 다음을 표시한다.

- 날짜 숫자
- 운동 카테고리 색상 점
- 서로 다른 운동 종목 수를 `3종` 형식으로 표시

카테고리가 여러 개인 날은 최대 3개의 색상 점을 보여주고 나머지는 생략한다. 날짜를 누르면 동일한 날짜별 상세 기록 바텀시트를 연다.

달력 아래에는 가장 많이 한 운동과 카테고리 분포를 표시한다.

## 카테고리 분포

원형 차트 대신 휴대폰에서 읽기 쉬운 가로 막대형을 사용한다.

각 행에는 카테고리 이름, 비율, 항목 수를 표시한다. 비율은 선택 기간 전체 운동 항목 수 대비 해당 카테고리 항목 수로 계산한다.

운동 데이터가 없으면 모든 막대를 숨기고 빈 상태 안내를 표시한다.

## 날짜별 상세 기록 바텀시트

주간 행이나 월간 날짜를 누르면 현재 리포트 화면 위에 바텀시트를 연다.

상단에는 날짜와 해당 날짜의 운동 기록 횟수를 표시한다.

각 운동 항목은 다음 정보를 보여준다.

- 운동명
- 중량 운동: `60kg × 10회 × 3세트`
- 시간 운동: `20분`
- 사용자 운동: 저장된 `exerciseName` 우선, 없으면 현재 사용자 운동 이름, 마지막으로 `기타 운동`

각 `WorkoutLog` 단위로 느낌과 메모를 함께 보여준다.

- 느낌 라벨
- 메모가 있을 때만 메모 표시
- 해당 기록으로 지급된 팩 수

바텀시트는 배경 탭, 닫기 버튼, ESC 키로 닫을 수 있어야 하며 내부 내용이 길면 시트 안에서만 스크롤한다.

## 계산 모듈

통계 계산은 화면에서 분리해 순수 함수로 구현한다.

```ts
export interface WorkoutReportSummary {
  activeDays: number;
  sessionCount: number;
  exerciseCount: number;
  totalMinutes: number;
  totalSets: number;
  totalReps: number;
  topExercise?: {
    exerciseId: string;
    name: string;
    activeDays: number;
  };
  categoryBreakdown: Array<{
    category: ExerciseCategory;
    count: number;
    ratio: number;
  }>;
}

export function buildWeeklyReport(
  workoutLogs: WorkoutLog[],
  weekStart: string,
  customExercises: CustomExercise[],
): WeeklyWorkoutReport;

export function buildMonthlyReport(
  workoutLogs: WorkoutLog[],
  year: number,
  month: number,
  customExercises: CustomExercise[],
): MonthlyWorkoutReport;

export function buildDailyReport(
  workoutLogs: WorkoutLog[],
  date: string,
  customExercises: CustomExercise[],
): DailyWorkoutReport;
```

주간과 월간 결과에는 현재 기간 요약, 이전 기간 요약, 증감값, 날짜별 데이터가 포함된다.

## 모바일 레이아웃

리포트는 홈과 달리 내용이 길기 때문에 화면 본문이 세로 스크롤된다. 하단 메뉴 높이와 `safe-area-inset-bottom`만큼 하단 패딩을 확보해 마지막 통계와 달력 행이 메뉴에 가려지지 않도록 한다.

주요 요약 카드는 2열 또는 3열 그리드로 구성하되 360px 이하에서는 2열로 고정한다. 월간 달력은 7열을 유지하고 글자와 점 크기만 축소한다.

## 오류 및 예외 처리

- 알 수 없는 기본 운동 ID는 `exerciseName`이 있으면 해당 이름을 사용하고, 없으면 `알 수 없는 운동`으로 표시한다.
- 사용자 운동이 삭제되어도 과거 `exerciseName` 스냅샷을 우선 사용한다.
- 잘못된 중량·세트·반복 값은 음수가 되지 않도록 집계 시 0 이상으로 보정한다.
- 다음 기간 버튼은 현재 주·월에서 비활성화한다.
- 첫 기록 이전 기간으로 이동하지 않도록 이전 버튼을 비활성화한다. 기록이 하나도 없는 신규 사용자는 현재 기간만 표시한다.

## 테스트 기준

순수 함수 테스트에서 다음을 검증한다.

- 주간 범위가 월요일부터 일요일까지 계산되는지
- 월말과 연말을 넘는 이전·다음 기간 계산
- 동일 운동의 하루 중복이 인기 운동 날짜 수에 한 번만 반영되는지
- 시간, 세트, 반복 집계
- 현재 기간과 이전 기간 증감
- 사용자 운동 삭제 후에도 스냅샷 이름 유지
- 빈 주·월이 0 통계를 반환하는지
- 월간 달력의 날짜별 카테고리와 종목 수

UI 테스트에서 다음을 검증한다.

- 보상 화면에 세 번째 `운동 리포트` 탭이 표시되는지
- 주간·월간 전환이 가능한지
- 미래 기간 이동이 비활성화되는지
- 날짜를 누르면 상세 바텀시트가 열리는지
- 빈 기간 안내가 표시되는지

## 첫 버전에서 제외

아래 기능은 후속 버전으로 분리한다.

- 운동별 최고 중량과 총볼륨 분석
- 개별 운동의 변화 선 그래프
- 최근 6개월 장기 추세 그래프
- 리포트 이미지 공유 또는 PDF 내보내기
- 목표 추천과 AI 코칭
- 리포트 통계의 서버 동기화

첫 버전은 과거 기록을 찾고 주간·월간 운동 습관을 이해하는 데 집중한다.
