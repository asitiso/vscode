# 사용자 직접 입력 운동 설계

## 목표

오늘의 운동 기록 화면에서 기본 목록에 없는 운동을 사용자가 직접 추가하고, 이후에도 반복해서 사용할 수 있도록 한다.

이번 기능은 기록 편의성을 높이는 보완 작업이며, 이후 예정된 게임성 업데이트인 **카드 세트 컬렉션 + 세트 완성 특별상자 + 오늘의 세트 보너스**와는 분리한다.

## 사용자 흐름

1. 사용자가 기록 화면에서 `기타` 카테고리를 선택한다.
2. 기타 운동 목록 아래의 `새 운동 직접 입력` 버튼을 누른다.
3. 운동 이름을 입력한다.
4. 기록 방식을 선택한다.
   - 시간 기록
   - 무게·횟수·세트 기록
5. 저장하면 새 운동이 기타 목록에 추가되고 즉시 선택된다.
6. 다음 기록부터는 저장된 사용자 운동이 기타 목록에 계속 표시된다.

## 사용자 운동 데이터

기본 운동 정의와 사용자 운동 정의를 분리한다.

사용자 운동은 최소한 다음 정보를 가진다.

- `id`: 사용자 운동을 식별하는 영구 ID
- `name`: 표시 이름
- `category`: 항상 `etc`
- `logType`: `duration` 또는 `weight-reps-sets`
- `createdAt`: 생성 시각
- `updatedAt`: 마지막 수정 시각

사용자 운동에는 전용 캐릭터 이미지와 전용 카드 ID를 연결하지 않는다.

## 저장 정책

- 사용자 운동 목록은 앱의 기존 영구 저장 상태에 포함한다.
- 앱을 종료하거나 새로고침해도 유지한다.
- 과거 운동 기록은 사용자 운동 정의와 별도로 기록 당시의 운동 이름과 기록 방식을 보존한다.
- 사용자 운동을 삭제해도 과거 기록은 삭제하지 않는다.
- 삭제된 운동의 과거 기록은 저장된 표시 이름으로 계속 조회할 수 있어야 한다.

## 생성 규칙

- 빈 이름은 저장할 수 없다.
- 입력 전후 공백은 제거한다.
- 연속된 공백은 하나의 공백으로 정리한다.
- 공백을 정리한 결과가 빈 문자열이면 저장하지 않는다.
- 사용자 운동 이름 비교는 정리된 이름을 기준으로 대소문자를 무시한다.
- 같은 이름의 사용자 운동이 이미 있으면 중복 생성하지 않고 기존 운동을 안내한다.
- 기본 운동과 같은 이름이면 새로 만들지 않고 기존 기본 운동을 사용하도록 안내한다.
- 운동 이름은 최대 30자까지 허용한다.
- 30자를 초과하면 저장하지 않고 오류 메시지를 표시한다.

## 수정

기타 목록의 사용자 운동에는 관리 버튼을 표시한다.

수정 가능한 항목:

- 운동 이름
- 기록 방식

수정 시에도 생성과 동일한 이름 검증 규칙을 적용한다.

기록 방식 변경은 이후 새 기록부터 적용한다. 과거 기록의 구조와 값은 변경하지 않는다.

## 삭제

- 사용자 운동만 삭제할 수 있다.
- 기본 운동은 수정하거나 삭제할 수 없다.
- 삭제 전 확인 대화상자를 표시한다.
- 삭제 시 기타 목록에서만 제거한다.
- 과거 기록, 경험치, 주간 진행, 이미 지급된 보상은 유지한다.
- 현재 작성 중인 기록에서 삭제 대상 운동이 선택되어 있으면 선택을 해제하고 관련 미완성 입력값을 제거한다.

## 기록 화면 UI

`기타` 카테고리를 선택했을 때만 직접 입력 영역과 사용자 운동 관리 기능을 표시한다.

구성:

- 기존 기타 기본 운동 목록
- 저장된 사용자 운동 목록
- `새 운동 직접 입력` 버튼
- 생성·수정 폼
  - 운동 이름 입력
  - `시간 기록` 선택
  - `무게·횟수·세트 기록` 선택
  - 저장
  - 취소

사용자 운동은 기본 운동과 같은 선택 칩 또는 목록 스타일을 사용하되, 관리 버튼으로 사용자 운동임을 구분한다.

작은 모바일 화면에서도 이름 입력, 기록 방식 선택, 저장·취소 버튼에 접근할 수 있어야 한다.

## 기록 및 통계 처리

사용자 운동 기록도 기본 운동 기록과 동일하게 처리한다.

- 오늘 운동 횟수에 포함
- 주간 목표 횟수에 포함
- 오늘 활동 통계에 포함
- 시간 또는 세트·반복 수 집계에 포함
- 최근 운동 목록에 포함
- 경험치 계산에 포함

사용자 운동은 `기타` 카테고리 통계로 집계한다.

## 보상 처리

사용자 운동을 포함한 운동 기록 완료 시 기존 보상상자 지급 규칙을 그대로 적용한다.

- 사용자 운동 전용 카드는 생성하지 않는다.
- 개봉 결과는 기존 카드 후보군에서 선택한다.
- 카드 확률, 천장, 중복 성장, 별 단계, 개봉 연출은 변경하지 않는다.
- 사용자 운동은 카드 도감 세트 완성 조건에 포함하지 않는다.

## 호환성과 마이그레이션

- 기존 사용자 저장 데이터에는 사용자 운동 목록이 없으므로 기본값은 빈 배열로 처리한다.
- 기존 운동 기록과 카드 데이터 구조를 깨지 않아야 한다.
- 저장 데이터 로드 시 누락된 사용자 운동 필드는 자동으로 빈 배열로 보정한다.
- 앱 업데이트 전 데이터가 그대로 로드되고 기록·도감·보상 기능이 정상 동작해야 한다.

## 오류 처리

사용자에게 구체적인 오류를 표시한다.

- 이름을 입력해 주세요.
- 이미 저장된 운동입니다.
- 기본 운동 목록에 있는 운동입니다.
- 운동 이름은 30자 이하로 입력해 주세요.

저장 실패 시 폼 입력값을 유지해 사용자가 다시 시도할 수 있도록 한다.

## 테스트 범위

### 생성

- 시간 기록 운동 생성
- 무게·횟수·세트 운동 생성
- 생성 직후 선택 상태
- 새로고침 후 목록 유지

### 검증

- 빈 이름 차단
- 공백만 있는 이름 차단
- 연속 공백 정리
- 사용자 운동 중복 차단
- 기본 운동 이름 중복 차단
- 30자 최대 길이 검증

### 수정·삭제

- 이름 수정
- 기록 방식 변경
- 삭제 확인 및 취소
- 삭제 후 목록 제거
- 삭제 후 과거 기록 유지
- 작성 중 선택된 운동 삭제 처리

### 기록·보상

- 시간형 사용자 운동 저장
- 세트형 사용자 운동 저장
- 오늘 활동과 주간 목표 반영
- 경험치 반영
- 보상상자 지급
- 기존 카드 후보에서 정상 개봉

### 회귀

- 기본 운동 선택과 기록
- 카드팩 지급 및 개봉
- 레벨 경험치 팝업
- 캐릭터 상호작용
- 사용자 운동이 카드 세트 완성률에 영향을 주지 않음

## 범위 제외

이번 작업에서는 다음을 구현하지 않는다.

- 사용자 운동 전용 카드 또는 이미지
- 사용자 운동을 카드 세트에 포함
- 운동 공유 또는 서버 동기화
- 사용자 운동 정렬 순서 변경
- 즐겨찾기와 사용 빈도 자동 정렬
- 새로운 재화나 별도 보상 규칙
