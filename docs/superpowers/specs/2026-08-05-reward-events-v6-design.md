# 보상 이벤트 6차 설계 — 연속 개봉 콤보와 진화·도감 축하

## 목표

여러 개의 미개봉 팩을 한 흐름에서 연속으로 열 수 있게 하고, 연속 개봉 횟수에 따라 콤보 감각을 강화한다. 카드가 별 성장 기준에 도달하거나 도감 카테고리가 채워질 때는 일반 카드 공개와 분리된 축하 연출을 제공한다.

## 핵심 원칙

- 기존 카드 확률, 지급 수량, 천장 로직은 변경하지 않는다.
- 각 팩은 기존 `OPEN_PACK` 액션으로 한 번만 지급한다.
- 서버 및 `AppState` 저장 구조를 추가하지 않는다.
- 연속 개봉 목록은 현재 `unopenedPacks`에서만 계산한다.
- 연출을 건너뛰어도 모든 카드 결과와 저장 상태는 동일해야 한다.
- 한 개의 팩만 있을 때는 기존 단일 개봉 흐름을 그대로 유지한다.

## 사용자 흐름

1. 개봉 화면 진입 시 현재 팩을 포함한 미개봉 팩 수를 확인한다.
2. 팩이 2개 이상이면 상단에 `연속 개봉 1/N`과 콤보 게이지를 표시한다.
3. 현재 팩을 개봉하고 카드 결과 및 성장 이벤트를 확인한다.
4. 다음 미개봉 팩이 있으면 최종 버튼을 `다음 팩 개봉`으로 바꾼다.
5. 다음 팩으로 이동할 때 화면을 닫지 않고 콤보 전환 애니메이션을 재생한다.
6. 마지막 팩까지 개봉하면 세션 전체 결과 요약을 보여준다.
7. 세션 중 별 성장 또는 진화가 발생하면 전용 진화 축하 화면을 삽입한다.
8. 신규 카드로 특정 운동 카테고리의 보유 카드가 모두 채워지면 카테고리 도감 완성 축하를 삽입한다.

## 연속 개봉 콤보

### 콤보 단계

- 1개째: `COMBO START`
- 2개째: `COMBO x2`
- 3개째: `COMBO x3`
- 4개 이상: `MAX COMBO`

콤보는 보상 확률이나 카드 등급에 영향을 주지 않고 시각·음향 연출에만 사용한다.

### 시각 변화

- 콤보 2: 상단 게이지 발광과 파티클 증가
- 콤보 3: 배경 회전 광선과 카드팩 진입 속도 강화
- 최대 콤보: 금빛 테두리, 화면 가장자리 펄스, 전용 완료 효과음

### 중단 처리

사용자가 도감으로 이동하면 현재까지 개봉한 결과만 저장된다. 남은 팩은 기존 미개봉 상태로 유지된다.

## 세션 결과 데이터

화면 내부 상태로만 다음 정보를 누적한다.

```ts
interface ComboResultItem {
  packId: string;
  cardId: string;
  rarity: CardRarity;
  isNew: boolean;
  previousStarLevel: number;
  currentStarLevel: number;
  evolved: boolean;
}
```

이 목록은 새로고침 후 복원하지 않으며 앱 저장 상태에 추가하지 않는다.

## 카드 진화 축하

### 발생 조건

- 카드 획득 후 별 단계가 이전보다 상승한 경우
- 특히 4성 도달 시 `evolvedIllustrationAsset`이 존재하면 진화 완료로 취급

### 연출

- 2성: 별 하나가 추가되는 짧은 성장 연출
- 3성: 카드 테두리가 강화되는 중간 진화 연출
- 4성: 기존 카드와 진화 일러스트가 교차 전환되는 전체 화면 연출

4성 진화 화면에는 다음을 표시한다.

- `FINAL EVOLUTION`
- 카드 이름
- `특별 일러스트 해금`
- 진화 전후 별 단계

## 도감 카테고리 완성 축하

### 계산 방식

카드 정의의 `exerciseId`를 운동 정의와 연결해 운동 카테고리를 구한다. 해당 카테고리에 속한 카드 정의 중 사용자가 보유한 카드의 비율을 계산한다.

### 발생 조건

이번 신규 카드 획득으로 카테고리 보유율이 처음 100%가 된 경우에만 표시한다.

### 연출

- 카테고리 아이콘 또는 이모지
- `카테고리 도감 완성!`
- `하체 5/5`, `유산소 3/3` 형태의 완성 수치
- 완성 카드의 작은 미리보기 목록

카테고리 완성은 별도 영구 플래그를 저장하지 않는다. 현재 팩이 신규 카드이고 획득 전 보유율이 100% 미만, 획득 후 100%인지 비교해 판단한다.

## 최종 종합 결과

마지막 팩 이후 다음 정보를 한 화면에 표시한다.

- 개봉한 팩 수
- 신규 카드 수
- 중복 카드 수
- 별 성장 횟수
- 최고 등급 카드
- 이번 세션 카드 미리보기 가로 목록

버튼은 다음 두 개를 제공한다.

- `결과 다시보기`: 세션 결과 요약만 다시 재생하며 보상을 재지급하지 않는다.
- `도감으로 이동`: 기존 `onDone`을 호출한다.

- 콤보 단계 계산
- 세션 통계 계산
- 카테고리 카드 정의와 완성 상태 계산

- 현재 팩과 다음 팩의 전환
- 세션 결과 누적

### `src/screens/RewardEventsV6.css`

- 콤보 게이지

## 오류 및 예외 처리

- 다음 팩이 이미 다른 경로에서 개봉되었으면 최신 `unopenedPacks` 기준으로 건너뛴다.
- 결과 카드 정의를 찾지 못하면 해당 팩을 세션 목록에서 제외하고 다음 팩으로 이동한다.
- 카테고리 매핑이 없는 카드는 카테고리 완성 계산에서 제외한다.
- 브라우저 동작 감소 설정에서는 교차 전환과 화면 흔들림을 제거한다.

## 검증 기준

1. 미개봉 팩이 1개면 기존 단일 개봉 UI가 유지된다.
2. 미개봉 팩이 여러 개면 화면을 닫지 않고 순서대로 개봉할 수 있다.
3. 각 팩은 한 번만 지급되고 새로고침 후 남은 팩 상태가 정확하다.
4. 콤보 단계가 개봉 순서에 맞게 증가한다.
5. 2성·3성·4성 도달에서 서로 다른 성장 연출이 나온다.
6. 4성 진화 일러스트가 있는 카드만 최종 진화 화면을 표시한다.
7. 신규 카드로 카테고리가 처음 완성될 때만 완성 축하가 나온다.
8. 최종 종합 결과의 신규·중복·성장 수치가 실제 개봉 결과와 일치한다.
9. 결과 다시보기로 카드가 중복 지급되지 않는다.
10. 모바일 저높이 화면에서도 다음 팩 버튼과 도감 이동 버튼에 접근할 수 있다.
